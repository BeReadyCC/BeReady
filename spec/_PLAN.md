## 一、项目是什么

**BeReady**：在长期异常状态（社会系统崩溃——战争 / 灾害 / 末日，人与人不再信任）下，一个普通家庭逐步建立的基本生存能力知识库。

- 输出**崩溃基调**的简洁实用内容，杜绝和平时期科普。
- 终极语境：一个饿着肚子、孤立无援、没有警察可叫的人，看完一条内容能不能立刻用。

## 二、终极考核目标（最高验收标准）

用户原话（2026-09-17）：**"如果真的末日，我带着这份资料，能否很好活下去，如果不能，还差些什么，这是终极考核目标。"**

首轮评估结论（147 节点时，见 `_progress/025.md` 与记忆）：

- **短期（崩溃后 1-4 周）覆盖扎实**：水 / 食物 / 火 / 庇护 / 安全 / 急救 6 项已建、崩溃基调，能处理「找水·处理水·找食·生火·保暖·止血包扎」最紧急的事。
- **中期（1-6 个月）致命缺口**：①卫生（脏病腹泻脱水是最快死因，完全空白）；②工具（刀斧锯绳，一切行动的放大器）；③储存（散在食物章节，未独立）。
- **长期（6 个月以上）断层**：种植 / 生产（食物耗尽后无出路）、稳定水源（水 L4 方向未展开）、能源（照明 / 发电）、越冬规划（整合视角缺失）、导航（野外定位）、中草药（药品断供替代，待定）。
- **根本局限**：资料是"知识"不是"技能"——生火 / 止血 / 失温处理等有时间窗口的硬技能必须提前练，光看资料来不及。

后续所有续建 / 回改，都以「填这个考核的缺口」为方向。

## 六、写作约束速查（完整版见两个 spec 文档）

- **第一原则**（core.md）：崩溃背景 + 简洁实用 + 宁缺毋滥；结构 L1-Ln 仅参考，不死板逐级。
- **红线**：不写人、不视人为威胁；可写自我保护（低调、减少暴露、避免冲突），不把他人刻画为威胁对象。
- **非城市场景**：崩溃后野外 / 丛林 / 山区是原始生存理想区域，为默认视角之一。
- **药品与可自制资源**：之初搜集常见药品及用途；不需现代工业能做出来的资源要记入 + 写核心制作步骤（如木炭）。
- **崩溃测试自检**：孤立无援、叫不到帮助的人看完能不能立刻用？不能就不收或重写。
- **口吻**：命令式清单，篇幅精简；删「来源」节、「为什么」节；关键原理压进「注意」或一句话导语。
- **清和平假设**：报警 / 报修 / 送医 / 求救 / 官方指示 / 公共供水点 / 维修人员等「可依赖解法」一律去掉——「没有」是前提不是假设。
- **校验清单**：front matter 四件（filename/title/level/category/status）齐全；title 全库唯一且与 H1 一致；level 与目录一致；Wikilink 能解析（index 里的待建链接是预告清单，不是死链，不要批量"修"）。
