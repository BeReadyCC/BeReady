# 无电冷藏

> 没有冰箱，肉、鱼、奶、剩饭一天就馊。会做几个不用电的「冷」地方，就能让最不经放的东西多撑几天到几周。

## 立即知道

* 不用电也有三条冷路：**地下**（越深越凉、温差越稳）、**蒸发**（水汽带走热）、**夜风**（夜里温度低）。
* 三种做法：蒸发冷却（当天能做）、地窖 / 泉井冷藏（长期）、储冰（冬天存夏天用）。
* 肉、鱼、奶坏得最快，**做出来先吃**；干货最经放，留到最后。

## 怎么做

### 一、蒸发冷却（当天就能做，最省事）

1. 两个陶罐或盆套起来，中间夹一层湿沙或湿布。
2. 外罐一直保持潮——水蒸发会带走热。
3. 盖上湿布盖，放在**通风、阴凉、背风**处。
4. 能比外面低好几度，放剩饭、蔬菜、水果能多撑一两天。

* 越干的天越管用；回南天、潮湿闷热时蒸发慢，降温效果大打折扣，别只靠它。
* 判断在工作：手摸外罐是凉的、湿布一直潮着。

### 二、地窖 / 深坑冷藏（长期）

1. 挖深坑或用地窖（见 [[地窖与埋藏]]），越深越凉、温度越稳。
2. 肉、奶吊在窖里，离地、离墙，保持通风。
3. **夜里**开窖口放冷气进来，**白天**盖严别让热气进去。
4. 窖里放一盆井水或湿沙，能再降一点。

* 判断成没成：窖里手探着明显比地面凉，且没有异味。

### 三、泉水 / 溪水冷藏

1. 把吃的装进能密封的容器（见 [[密封储存]]），沉进流动的凉水里。
2. 用绳绑牢、石头压住，别被水冲走。
3. 井水同理，把容器吊到井里接近水面的地方。

* 只在有干净、流动、发凉的水的地方管用。

### 四、储冰（冬天存，夏天用）

1. 冬天把冰或压实的雪，存进深坑或厚墙小窖，一层冰盖一层厚草、锯末、土隔热。
2. 堆满压实，别留缝漏热气。
3. 开春冰还能撑一段时间，专放最怕坏的肉、奶。

* 这招要**提前在冬天动手**，不是热天能临时补的。

## 判断成没成

* 蒸发罐：外罐凉、湿布潮、里面东西明显比室温凉。
* 地窖：手探明显凉、通风、无异味。

## 注意

* 冷藏只是「拖慢」，不是「放不坏」——闻着馊、摸着黏、长了霉就别吃，见 [[食物安全]]。
* 肉鱼奶最不经放，别存过一两天还舍不得扔，吃了坏的更糟。
* 窖里可能缺氧、可能塌，进出当心，见 [[地窖与埋藏]]。
* 存的东西要密封，别让虫鼠爬进去，见 [[密封储存]]。

## 不够怎么办

* 没有陶罐、没有地窖：把湿布直接裹在食物上，挂通风阴凉处，也能降一点温。
* 实在没条件冷藏：当天弄到的肉鱼当天吃完，剩下的做成能放的（腌、晒、熏），见 [[食物加工]]、[[食物脱水]]。
