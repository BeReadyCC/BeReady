# 干燥燃料

> 晾干以月计，临用现干不存在。柴要在需要之前几个月就开始晾。

## 立即知道

| 燃料 | 干燥要点 |
|---|---|
| 青柴 | 含水率从 50% 以上降下来要数月；劈开晾比整段快得多 |
| 受潮的干柴 | 重新晾几天到几周 |
| 秸秆、干草 | 蓬松堆放、防雨防压实；受潮会自热 |
| 纸、纸板、引火物 | 受潮即废，重点是防潮不是晾干 |
| 炭、固体酒精 | 怕吸潮，密封保存 |
| 果核、玉米芯、坚果壳 | 晒透后可做辅助燃料 |

## 怎么做

### 晾柴

1. **离地架空**：垫石块、木条，不直接落地；
2. **留缝排开**：让空气穿过；
3. **只盖顶、不包裹**——全包塑料布会把湿气闷在里面发霉；
4. 选通风向阳处，远离墙根草丛；
5. **先晾的先烧**，新柴补进晾晒区，轮换。

### 防潮保存

* 干透的柴移入储存区，见 [[燃料储存]]；
* 纸类引火物装密封袋；
* 雨季前检查一遍存量，受潮的挑出来回炉边烘或回晾晒区。

### 判断干没干

用 [[木材燃料]] 的四条：端面裂纹、敲击清脆、手感轻、树皮松脱。

## 注意

* **柴堆不要贴着房子堆**——虫蚁通道加引火物贴墙，双重问题。
* 干草、秸秆压实受潮会**自热自燃**——蓬松存放、勤翻动。
* 没干透的柴塞进炉子，等于把烟道当烟熏炉，焦油迅速积聚。
* 入冬前、雨季前各整理一次批次——干燥这件事，临时抱佛脚没用。
