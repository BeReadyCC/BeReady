# 火力控制

> 燃料有限时，控制火力就是控制储备的寿命。会控火和不会控火，同样一堆柴能差出一倍天数。

## 立即知道

> **火力 = 燃料供给 × 通风量**

调控手段只有三个：

| 想要 | 动作 |
|---|---|
| 调大 | 添细柴、开大进气、架空燃料 |
| 调小 | 停止添柴、压小进气、让火烧透 |
| 维持中火 | 粗柴慢喂、进气半开 |

第三个常被忽略的手段：**锅与火的距离**。外焰温度最高，锅底架在火苗尖端——同样的火，差几厘米，传热完全不同。

## 怎么做

### 按用途定火力

| 用途 | 火力 | 燃料策略 |
|---|---|---|
| 烧水、快炒 | 大火 | 细柴、架空、全开进气，短时高输出 |
| 焖、炖、煮粥 | 中火转微火 | 粗柴慢喂，水开即压火 |
| 取暖过夜 | 微火（闷烧） | 大块实柴 + 极小进气 |
| 烘干、保温 | 余火 | 不添新柴，用余烬 |

### 压火与封火

* **压火**：灰烬覆盖火面、或码放大块实柴，同时关小进气——减慢燃烧，不是灭火；
* **封火过夜**（炉具）：燃烧层用灰半埋、进气压到最小，第二天扒开加柴复燃；
* 压火 ≠ 熄火：封火状态仍在燃烧，**仍然产生一氧化碳**，见 [[室内用火风险]]。

### 效率自检

**火苗应舔在锅底，不是绕锅边往上蹿。**

* 火苗高出锅底很多 → 热在加热空气，调低锅或减柴；
* 火苗够不着锅底 → 调高锅或加大火力；
* 火苗被锅压得发暗冒烟 → 缺氧，架空燃料或开大进气。

## 注意

* **不要用水把火调小**——浪费热量还有蒸汽烫伤风险。
* 超过通风能力的柴只会压低火温、增加烟，不为"旺"一味加柴。
* 封火过夜前确认通风仍在——密闭房间封火是最典型的一氧化碳场景。
* 火力突然变大且持续，多半是燃料塌落露出新通风道——看一眼火是不是要跑出范围。
