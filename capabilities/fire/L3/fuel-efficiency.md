# 燃料效率

> 同样一堆柴，效率差能差出数倍。效率不是"烧得旺"，是让热量进锅，而不是上天。

## 立即知道

开放火堆的热量，大部分随烟和热气流散走。效率手段的原理只有一个：**减少旁路损耗**。

按投入产出排序：

| 手段 | 投入 | 效果 |
|---|---|---|
| 盖锅盖 | 零 | 缩短加热时间 |
| 挡风 | 一块板 / 石垒 | 风里烧火损失极大，挡风立竿见影 |
| 水量按需 | 零 | 烧 1 L 和 3 L 的燃料差三倍 |
| 换炉具 | 一次搭建 | 长期收益最大，见 [[简易炉具]] |
| 焖制代替久煮 | 零 | 水开后关火焖，用余热完成 |

## 怎么做

### 做饭流程里的效率习惯

1. **先想后烧**：这一餐几个锅、什么顺序，一次生火全部完成；
2. **容器匹配火力**：小锅不架大火上；
3. **盖子常备**：没有锅盖用盘子、木板压湿布；
4. **豆类杂粮先浸泡**再煮，时间大幅缩短；
5. **利用余热收尾**：粥饭沸腾后移到余烬上焖熟。

### 自检

每次烧完问一句：**这堆火有多少热真的进了食物？**

* 火苗舔锅底 → 对了；
* 火苗绕锅边蹿 → 锅小火大，浪费；
* 风把火焰吹歪 → 缺挡风；
* 水开前烟特别大 → 柴太湿，见 [[干燥燃料]]。

## 注意

* **效率不能牺牲安全**：挡风板用不可燃材料；不为省燃料在密闭空间压火取暖。
* 沸腾之后再大火只是把水烧掉。
* 减水量要有度，水太少会糊底烧穿锅。
* 边界：本节点讲**怎么烧**；一份热多做几件事见 [[热量利用]]；留住热见 [[保温与节能]]；燃烧完全程度见 [[燃烧效率]]（L4）。
