# 火用于食物加工

> 这一节只讲**火的角度**——用什么火型、哪个阶段、多久。做什么、做熟的标准见 [[基本烹饪]] 与 [[食物安全]]。

## 立即知道

火不是一个状态，是一条**时间线**：

> 点燃 → 大火（预热）→ 炭床（烹饪主力）→ 余烬（焖与保温）→ 熄灭

**多数烹饪发生在炭床阶段，不是明火阶段。** 直接架明火上烤的结果几乎总是：外焦内生。

火型选择：

| 火型 | 适合 | 要点 |
|---|---|---|
| 明火快烤 | 薄片肉、蔬菜串 | 食材要薄，离火一拳以上 |
| 余烬焖烤（埋灰） | 根茎、整块食材 | 裹泥/裹叶防焦，埋进灰下炭层 |
| 持续小火炖煮 | 汤、粥、杂粮 | 久火慢炖，见 [[火力控制]] |
| 石板烤 | 薄饼、片状食材 | 石板必须干透，预热后上食材 |
| 烟熏 | 长期保存肉鱼 | 低温长时间，风险见下 |

## 怎么做

### 按时间线安排

1. 生火后**先让明火烧成炭床**，这段时间烧水，见 [[火用于饮水处理]]；
2. 炭床摊开分区：炭厚处猛、炭薄处温；
3. 慢炖的架炭床边，焖的埋灰里；
4. 餐后余烬继续焖下顿的根茎，再收尾熄火。

### 烟熏的特殊要求

* 目的是**脱水 + 表面抑菌**，要稳定的低温烟（不见明火）和足够时间；
* 熏材用果木、硬木湿锯末，**不用松脂多的针叶木**；
* 烟熏肉制品有肉毒杆菌等风险，**食用前必须彻底加热**，没把握不要做，见 [[可食与不可食]]。

## 注意

* **明火不是烹饪阶段**——急着在明火上做 = 外焦内生 + 浪费燃料。
* 耐热毒素的边界不变：米酵菌酸、黄曲霉毒素等，任何火型都无效，只能丢弃，见 [[变质判断]]。
* 余烬焖烤尤其容易外熟内生，肉类的做熟标准见 [[食物安全]]。
* 含水石头受热崩裂，石板必须干透。
* 全程用工具翻动，不徒手。
