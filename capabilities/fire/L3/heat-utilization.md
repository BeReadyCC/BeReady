# 热量利用

> 每次生火都有固定开销：引火、预热、看管。生火次数越少、一次火用得越满，储备活得越久。

## 立即知道

一次火可以同时产出的东西：

| 火的位置 | 能做什么 |
|---|---|
| 火上（明火） | 烧水、快炒、煮沸消毒 |
| 火边（热辐射区） | 烘干衣物、慢炖、化雪 |
| 余烬 | 焖熟食物、保温、烤根茎 |
| 灰烬 | 焖烤、保存炭火 |
| 烟 | 熏制（需要专门控制，谨慎） |

核心思路：**把一次火当成多工位的加热平台来规划**，不是一次火干一件事。

## 怎么做

### 一次火的排程

1. **生火阶段（大火）**：先烧全天的饮用水——火力最旺时烧水最快；
2. **烹饪阶段（中火）**：煮饭炖菜，同时在火边烘干衣物、化雪备水；
3. **余火阶段**：根茎埋进余烬焖，余烬上保温已做好的食物；
4. **收尾**：余炭回收、彻底熄灭，见 [[火源熄灭]]。

### 计划要点

* **集中用火**：一天两次完整的火，胜过五六次零星点火——每次点火的引火物、工具寿命、看管都是成本；
* 热水需求提前排序：先满足用量最大的（饮用水）；
* 衣物离火半臂以上，翻面，防烤焦和火星烫洞；
* 把当天的用火排程写在纸上、贴在灶边——一番火先干哪件、再干哪件，省得临时一件一件重新点。

## 注意

* **一次做太多吃不完，是把利用热量变成浪费食物**——按真实食量排程，见 [[避免食物浪费]]。
* 衣物靠近火永远是风险，看管不能省。
* 烟熏食品有肉毒杆菌等风险，没有把握不要做，见 [[可食与不可食]]。
* 多锅同上，先确认炉架承重和稳定。
* 火烧得越久周边越干，隔离圈往外收，见 [[火与环境]]。
