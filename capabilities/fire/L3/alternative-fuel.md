# 不同燃料

> 常规燃料耗尽后，环境里能烧的东西不少——难点不在找到，在认出它烧起来是什么脾气。

## 立即知道

| 燃料 | 脾气 | 用法 |
|---|---|---|
| 干草、芦苇、枯叶 | 极易燃、极快、几乎不产热 | 只当引火物 |
| 桦树皮、松脂、松木节 | 含油含脂，潮湿也能点 | 最好的天然引火物 |
| 动物干粪块（食草动物） | 热值中等，烟大 | 干透后户外或强通风用 |
| 废食用油、动物油脂 | 火小而持久 | 油灯 |
| 泥炭 | 潮湿地区地下可挖，需晾干 | 慢火燃料 |
| 煤、焦炭 | 热值高、耐烧 | **只能户外或极强通风** |
| 纸板、木质包装 | 随处可得 | 常规补充 |

判断新燃料的三问：

1. **烧起来烟大吗？** 烟大 = 毒气风险 + 容易暴露；
2. **需要多干？** 含水的先晾，见 [[干燥燃料]]；
3. **烧完留什么？** 留焦油、异味、毒灰的，只在室外用。

## 怎么做

### 环境扫描顺序

1. 先找**干植物类**（干草、枯枝）——安全易得，当引火；
2. 再找**高脂类**（桦树皮、松脂）——关键时刻点火用；
3. 最后考虑**粪燃料、泥炭**这类需要处理的，作长期补给。

### 粪燃料

* 必须**完全干透**（色浅、质轻、掰开无潮气）；
* 烟大味重，只适合户外；
* 与木柴混烧，不单独全靠它；
* 处理后洗手。

### 废油灯

金属浅盘 + 棉布做芯，油浸透棉芯。火焰小、照明够用，但油烟大，只在通风处短时用。

## 注意

* **不能烧的硬清单仍然有效**：塑料、复合板、油漆木材、汽油，见 [[基本燃料]]。
* 煤在室内烧是一氧化碳第一风险源，没有烟道的室内一律不烧煤，见 [[安全用火]]。
* 别拿废油泼火引燃——泼向火源的液体燃料都会闪燃。
* **烧一种新燃料前，先算体力账**：收集它花的力气，值不值它放出的热。
