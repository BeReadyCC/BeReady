# 基本燃料

> 断供那天，屋子里已经有燃料了。问题是哪些能烧、哪些烧了就出事。

## 立即知道

按能不能烧、适合干什么分类：

| 燃料 | 适合 | 注意 |
|---|---|---|
| 管道燃气 / 罐装液化气 | 烹饪主力，火候可控 | 存量有限，见 [[燃气安全]] |
| 酒精（医用酒精、高度白酒） | 小炉具短时加热 | 热值低、火焰几乎看不见、易闪燃 |
| 蜡烛 | 照明 | 热输出很低，别指望取暖 |
| 木柴、木炭 | 持续取暖、长时间烹饪 | 需要通风排烟 |
| 纸张、纸板 | 只作引火物 | 烧得快、火星易飞 |
| 实木家具 | 拆解后当柴火 | 复合板、油漆面**不能烧** |
| 食用油 | 极端情况做油灯 | 油烟大、易泼洒起火 |

两个选法：

* **按用途**：快速加热用燃气酒精；持续取暖用木柴木炭；照明用蜡烛油灯。
* **按顺序**：先用可控的（燃气、酒精），再用要管理的（木柴木炭），纸和干草留作引火——**烧一样少一样，省着用**。

## 怎么做

### 先盘点

断供后立刻清点一次：

* 燃气还剩多少（罐装提一提重量）；
* 木柴、木炭、固体酒精有多少；
* 蜡烛、油灯、灯油有多少；
* 哪些实木家具可拆。

### 不能烧的（硬清单）

* **塑料、橡胶、泡沫**——剧毒气体；
* **复合板、贴面板、刨花板家具**——粘合剂燃烧释放毒气；
* **油漆、涂漆木材**——涂层有毒；
* **汽油**——挥发极快，靠近火源瞬间爆燃；
* **煤炭在密闭房间**——一氧化碳致死，见 [[安全用火]]。

## 注意

* **不要向明火或高温物体倒酒精、汽油。** 酒精火焰白天几乎不可见，"看不见"不等于"没有"。
* 蜡烛只用来照明，它本身也是火源。
* 燃烧任何东西都消耗氧气、产生一氧化碳，室内用火必须通风。
* **烧掉的东西不会回来。** 烧家具前想清楚，先烧损失最小的。
* 燃料盘点之后要省着用——补给断了就是断了，别按"过两天会恢复"的节奏烧。
