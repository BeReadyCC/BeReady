# 安全用火

> 秩序没了，失火没人来救。一场火灾烧掉的不只是住处，是你全部的储备。

## 立即知道

四条铁律：

1. **火不离人。** 点着的火必须有人看；人离开或睡觉，火必须熄灭。
2. **隔离可燃物。** 火的四周和上方留一圈净空，至少一米，地面无干草、纸、油布。
3. **密闭空间必须通风。** 任何明火都耗氧、产一氧化碳。
4. **先备好灭火手段再点火。** 水、沙、湿毯、锅盖，至少一样在手边。

### 一氧化碳：看不见的死因

一氧化碳无色无味，是密闭空间用火最主要的死因。危险源排序：煤炭 > 木炭 > 燃气热水器 > 明火柴堆。**炭火取暖是头号场景。**

判断方法只有一个——**同屋的人同时出现**这些症状，基本就是一氧化碳：

* 头晕、恶心、无力，一起发作；
* 开窗缓解，关窗加重。

处理只有一个动作：**立即开窗、全员离开**，不要留在屋里"缓一缓"。

## 怎么做

### 点火前的位置检查

* 周围一米内无可燃物，上方无悬挂物；
* 地面是石面、金属盘或砖，不是地毯、木地板、干草地；
* 附近没有油瓶、酒精、喷雾罐；
* 逃生方向畅通——**火不在你和大门之间**。

### 紧急情况处置

| 情况 | 正确做法 | 绝对不要 |
|---|---|---|
| 油锅起火 | 关火、盖锅盖 | **泼水**（爆溅扩散） |
| 衣物着火 | 停、躺、滚 | 站着跑 |
| 酒精闪燃 | 湿毯覆盖 | 用水冲（酒精浮在水面继续烧） |
| 电气起火 | 先断电再灭火 | 带电泼水 |
| 怀疑一氧化碳 | 开窗、全员撤 | 留在室内 |

### 有儿童、宠物时

* 与火源之间做**物理隔离**，口头警告无效；
* 蜡烛放不易碰倒的浅盘里，远离窗帘被褥。

## 注意

* 有条件就备一个一氧化碳报警器——人睡着后对中毒零感知。
* 不要用打火机在黑暗中查看燃气泄漏处，见 [[燃气安全]]。
* 灭火手段在点火**之前**备好，着起来再找就晚了。
* 室外、室内的场景深化见 [[室外用火安全]] 与 [[室内用火风险]]。
