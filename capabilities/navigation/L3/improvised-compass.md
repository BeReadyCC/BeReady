# 自制罗盘

> 天阴得看不出太阳、密林里抬头只有一线天，这时只有地磁靠得住。一根磁化的针，加一碗水，就是罗盘。

## 立即知道

**磁化的铁针 + 能自由转动的托子 = 罗盘**。针指向南北；只要在针上标出哪头是北，就能一直用。

## 怎么做

### 一、做一根磁针

* **取材**：缝衣针、大头针、细钢针最好；铁丝能用但退磁快；不锈钢针磁性弱，不如碳钢针。
* **用现成磁铁磁化**（喇叭磁铁、旧扬声器、电机里的磁铁、冰箱贴磁条都行）：
  1. 针平放，**单向擦**：磁铁从针尾沿针身擦到针尖，抬起、回到针尾、再擦——**始终同一方向，绝不来回**。
  2. 擦 20～30 次。
  3. 来回擦会把磁性反复抵消，等于白做。
* **没有磁铁**：把针放在**南北向**（先用影子法、北极星定出南北）的木片或地面上，用小石轻敲针身几十下，再静置两三天，地磁会慢慢磁化它。很弱，但两种办法一起用更稳。

### 二、让针自由转（选一种）

* **浮水法（最容易做）**：找软木塞、泡沫、树皮、厚纸片，把磁针平穿过去，放在一碗静水上，针会慢慢转到南北向。
  * 要点：碗要**避风**（放坑里、草里，用身体挡风）；水面不能有油（有油针转不动）；针必须水平。
* **悬吊法（更抗风、更准）**：用细线（丝线、长头发、拆出的棉线单股）系在针的**正中间**，吊起来离开任何物体，针会转到南北向并稳定。
  * 要点：系点偏心会偏到一边；吊线不能有扭劲。
* **支点法**：针中间顶在竖直的针尖或细棍上，也能转，但容易掉、怕风。

### 三、认哪头是北（必须现场校一次）

1. 先用 [[方向判断]] 的**影子法**定出实实在在的北。
2. 看针——**哪一头指向北，就在那一头缠一小截红线或咬一个记号**。
3. 以后拿起来就用，不必再校。

### 四、用罗盘走直线

1. 把罗盘**放平**（用石头或木片垫平），等针停稳。
2. 看清你要去的方位（比如「东北」），在正前方**远处挑一个固定地物**——独立大树、孤立岩石、山头。
3. 朝那个地物走到，再看一次罗盘，重新挑下一个目标点。
4. **不要一路盯着针走**——人会自然走偏，靠远处目标点才走得直。
5. 走一段记一次「方位 + 步数」，攒成路线，见 [[坐标定位]]。

### 五、校准与保养

* **先挪开干扰源**：附近有铁器（刀、锅、钉、铁丝）、钢筋混凝土、电瓶、通电的线，针就会偏。用前把这些挪开一米以上，或换地方。
* **磁偏角**：磁北和真北不重合，差值各地不同（中国东部多偏西几度，西部反而可能偏东或接近零），**别背数字**。做法：就地用影子法定一次真北，看罗盘差了几个刻度，把这个差值记住，以后每次用前补回去。拿不准时以真北为准，罗盘只作快速指示。
* **退磁就重擦**：磁性会慢慢变弱，隔一段时间用已知方向校一次；偏得多了重新擦一遍。
* **收存**：别和铁器、磁铁堆在一起；用布包好单独放。

## 注意

* **别摔、别火烤**：敲击和高温都会削弱磁性，针烧到发红就彻底失磁。要清洁用布擦，别放在火边。
* **判断罗盘可不可信**：在同一地点转三圈松手，每次停在同一方向才可信；每次停的方向都不同，就是有干扰，或吊线有扭劲。
* 有太阳、有星星时，**罗盘和影子法互证一次**。对不上时信天象——磁偏角你不一定算得准。
* 罗盘是**天象不可用时的备份**，不是替代；两样都会，才不怕连阴一个月。
