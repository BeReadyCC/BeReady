# 种植

> 崩溃后超市不再补货，囤的食物吃一口少一口。种地不是爱好，是把「找饭吃」变成「产饭吃」——自己能产，就不必天天冒险出门找、不必和别人争。

种植解决一件事：食物耗尽之后，还有没有饭吃。本能力只写植物性食物（粮食、蔬菜、块茎）怎么从地里长出来。动物养殖、食物加工归后续「生产」能力，不在这里建。

## Level 划分

| Level | 能力目标 | 核心知识 |
|---|---|---|
| L1 · 立即可用 | 当天就能开始，不需要特殊材料：找块地、撒下能活的种子 | 3 |
| L2 · 需要条件/材料 | 留种、改土、施肥、灌溉、选对作物、对付草和虫 | 6 |
| L3 · 长期与规模（未展开） | 季节性安排、育种选种、扩大种植规模 | 0 |

判据：L1 当天就能动手、手边现成；L2 需要一定材料或长期照顾；L3 需要季节规划与批量管理。

## L1 · 立即可用

### 能力目标

从「找食物」转到「产食物」：先种能活、长得快、能量高的（土豆/红薯/豆/瓜/玉米），把一小块地真正种出东西来。

### 核心知识

* [[种植的基本逻辑]]
* [[基础种植]]
* [[播种]]

### 不够怎么办

* 种子用完、需要年年自己留种 → 进入 L2（[[种子保存]]）。
* 地瘦、长不好 → 进入 L2（[[土壤基础]]、[[肥料与养分]]）。
* 苗期缺水、旱季保水难 → 进入 L2（[[简单灌溉]]）。
* 不知道该种什么、怎么收 → 进入 L2（[[常见作物]]）。
* 草压苗、虫吃叶 → 进入 L2（[[杂草与病虫害]]）。

## L2 · 需要条件/材料

### 能力目标

让地越种越肥、种子年年不断、旱季也有收成，并把草和虫害压到不毁产的程度。

### 核心知识

* [[种子保存]]
* [[土壤基础]]
* [[肥料与养分]]
* [[简单灌溉]]
* [[常见作物]]
* [[杂草与病虫害]]

### 不够怎么办

* 需要按季节排种、错峰收获 → L3 的 [[季节性食物]]（方向）。
* 想要更稳更高产、自己选种育种 → L3 的 [[育种选种]]（方向）。
* 家人多、要成规模种 → L3 的 [[种植规模扩大]]（方向）。

## 待理清的问题

* **与 [[食物]] 分工**：本能力只写到「从地里种出来」，采收后的烹饪、储存、加工、脱水归食物与后续「生产」能力；不在这里复制。
* **与 [[采集]] 边界**：野外可食植物是「找」，种植是「产」；两者相接，本能力不重造采集节点。
* **粪肥与 [[粪便处理]] 衔接**：腐熟要求以卫生章节为准，本能力只强调「必须腐熟」，不重写标准。
* **「生产」能力待建**：动物养殖、食物加工明确不进种植，留待后续能力，正文已注明不重造。
* **低调措辞边界**：菜地选址只写到「不显眼、降低暴露」为止，不延伸到「防谁」。
