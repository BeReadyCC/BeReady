# 种植规模扩大

> 一小块够活命，要长期吃得饱、有结余，就得扩大。规模不是多撒种，是多块地、错开种、排得开——不然扩了也白扩。

## 什么时候该扩

* 现有地收的粮，不够吃到下季收成 → 该扩。
* 先算账：一天吃多少、一年吃多少、现有地一年产多少，差多少扩多少。

## 先扩「地」，还是先扩「水肥」

* 地多、没水没肥，照样薄收。先保证每块地都有水到（见 [[简单灌溉]]）、有肥可上（见 [[肥料与养分]]）。
* 别贪大：一块地种好，再开下一块。

## 多块地怎么排

* 分散开：一块受灾（旱、涝、虫、被糟蹋），还有别的顶着。
* 错开种：不同地种不同作物、不同播期，收成错峰——不一次全熟，也不一次全绝。
* 轮作：同一块地别连年种同一样，轮着种豆类恢复地力。

## 扩大不等于更累

* 优先扩「省力的」——土豆、红薯、瓜，一穴一收；比扩「费工的」——天天浇水除草的叶菜，划算。
* 体力有限，先保吃饭的地，再扩结余的地。

## 判断

* 结余信号：收的粮能吃满一年还有剩 → 规模够了，别盲目再扩。
* 不够信号：年年青黄不接 → 继续扩，或换更高产的作物。

## 注意

* 规模大 = 占的地方大、更显眼。选址仍要低调、分散、不显眼（思路见 [[种植的基本逻辑]]）。
* 别一次开太多地，忙不过来荒了，比不扩更糟。
