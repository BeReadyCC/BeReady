# 基本睡眠环境

> 睡觉是人最没防备的几个小时——睡眠环境的底线是：睡着之后不会变得更糟。

## 立即知道

睡前五查，缺一项就不算完成：

| 检查项 | 对象 | 常见问题 |
|---|---|---|
| 地面隔离 | 身下 | 地面导热 + 返潮，一夜带走全部热量 |
| 风雨 | 头顶与开口 | 半夜变天、塑料布松脱 |
| 安全 | 周围环境 | 上方坠物、涨水线、动物路径 |
| 通风 | 有火的场合 | 密闭 + 火 = 一氧化碳 |
| 工具就位 | 手边 | 火种、照明、刀、鞋——夜里要能立刻起来 |

## 怎么做

### 隔地面（最重要的一步）

* 硬垫 > 干草 > 瓦楞纸 > 叠起的衣物 > 什么都不垫；
* 有条件的做两层：下面隔潮（塑料布、树皮），上面隔热（干草、衣物）；
* **厚度要有**：干草、落叶至少堆 **10 厘米以上**（压下去还得剩这么厚）才顶得住夜里的传导散热，薄薄一层等于没垫；
* 睡的位置比周边略高一点，夜里渗水先积低处；
* 直接躺地时，身体靠传导散掉的热量比躺在干草上快得多——**半夜"冻醒"多半是身下没垫够，不是身上盖得少**。

### 布置

* **头朝高处、脚朝低处**，头背风；
* 开口用背包、衣物半堵——挡风留缝，有火时缝就是命；
* 手电 / 火种放在固定位置、闭眼能摸到；鞋尖朝外放在手边，遇险穿鞋就走。

### 环境

* 睡前收好食物：食物进密封袋、挂离地面或远离睡处，避免招来动物；
* 多人围睡、火/灯在中间，指定一人守夜轮换；
* 水边过夜必须确认水位线和上游天气，睡在涨水线之上。

## 注意

* **不要睡在车道、门口、排洪通道上**——再累也不行；
* 半夜听到异常（水声、石流、结构声）先带灯查看再决定，不要翻身继续睡；
* 失眠超过一晚说明环境有问题（太冷、太吵、太不安全），优先修环境而不是硬撑；
* 空间划分（睡区 / 生活区分开）属于持续居住，是 L2 的 [[生活区域划分]] 主题。
* "睡着后不更糟"是底线判断：白天的问题还有清醒的头脑处理，睡梦中出问题没人应对。五查每一项都是替睡着的自己值岗。
