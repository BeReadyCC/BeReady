# 临时避护

> 临时避护的目标不是"住得舒服"，是"今晚不被环境持续消耗"。

## 立即知道

临时避护的优先级从高到低：

| 优先级 | 做法 | 说明 |
|---|---|---|
| 1 | 利用现成遮蔽 | 车辆、桥洞、门廊、废弃建筑、大树下、岩檐下 |
| 2 | 用随身物品造遮蔽 | 雨衣、塑料布、帐篷、应急毯、大垃圾袋 |
| 3 | 用环境造遮蔽 | 倒木背面、岩石背风面、密灌木丛、雪坡挖进、土坎凹处 |
| 4 | 自建简易结构 | 需要材料与时间，进入 L3 再考虑 |

**规则：优先借用，再考虑建造。** 借来的遮蔽立刻可用；自建可能要花掉你最宝贵的几个小时和体力。

## 怎么做

### 身上就有的遮蔽

* 雨衣 / 大塑料袋：撑开挡雨，灌入空气后封口是坐垫，套在身上是防风层；
* 应急毯（银色薄膜）：银面朝内反射体温，朝外反射日光防晒，挂在开口处挡风；
* 睡袋 / 多余衣物：包裹躯干优先，其次头颈。

### 借用环境

* 找**背风面**：先看风从哪来，站到障碍物的背面；
* 岩檐、桥底、倒木：上方有遮挡、背后有依靠的组合最好；
* 面积不需要大——**遮蔽越小越暖**，小空间靠体温就能升温。

### 挖进去（雪地 / 土坡）

没材料、风又大时，最能挡风的地方在雪里、土里——掏出来的洞比搭起来的棚还挡风，而且是**零材料**的。

* **选地方**：结实的雪坡或雪堆，从**侧面**往里挖；雪檐下方、雪崩坡、冰裂缝附近绝对不挖。
* **尺寸**：够躺下、能坐起即可；洞顶留 **30 厘米以上**（薄了会塌）。挖出的土石堆在两旁当挡风矮墙。
* **冷井**：入口处挖一个比睡处更低的坑，人睡在略高的平台上——冷空气沉在低处，不会泡着你。
* **通风孔**：从里往外捅一个**拳头大的孔**，睡前和夜里都不能堵，洞口也别完全封死——**这是雪洞的命门**；在里面用火更要把孔开大，见 [[火]] 的 [[安全用火]]。
* **进洞前把身上的雪拍掉**（雪化了会湿透衣服，比不进去还冷）；睡垫、衣物隔一层再躺，别直接贴雪壁。
* **做标记**：洞口外插一根棍子或绑条布——雪洞从外面看就是一片雪，回头自己都找不到。
* **只住一两晚**：待久了内壁结冰、空间变小变潮，换个新洞比修旧洞省事。

* **土坎 / 树根下**：找向阳背风的土坎或大树根，把根部掏成能坐能躺的凹处；松土、有裂缝、上方有落石的坡不掏。

### 布置顺序

1. 先隔地面（隔潮隔冷），见 [[基本睡眠环境]]；
2. 再挡头顶的雨和风，见 [[防雨]]、[[防风]]；
3. 开口背风，大小以能进出为准，夜里用衣物或背包堵上（**雪洞、土洞例外——通风孔必须留着**）。

## 注意

* 车辆避险时**不要在密闭车内开火取暖**，一氧化碳会积聚；
* 废弃建筑先查结构（裂缝、滴水、异味），有燃气味立即离开；
* 塑料布压不牢会被风掀掉——用石块、水瓶等重物压边，别指望手扶；
* 不要把遮蔽建在 [[选择安全位置]] 里列出的任何危险位置上，借用的现成遮蔽同样要先过一遍选址检查。
* 失温、雨淋、风吹对身体的消耗是持续、累积的。临时避护解决的是"把消耗停下来"——哪怕简陋，只要切断风、雨、地面三个方向的接触，身体就有机会恢复。追求完美而拖延，比立刻钻进一个塑料袋危险得多。
