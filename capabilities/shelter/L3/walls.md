# 墙体

> 墙不是越密越好——先想清楚这面墙主要挡什么（风、雨、冷、视线），再决定做到哪一层。

## 立即知道

墙体功能的四个层级，由外到内逐层加：

| 层级 | 功能 | 材料 |
|---|---|---|
| 挡风层 | 断对流 | 枝条排、布、塑料布 |
| 遮雨层 | 导走雨水 | 塑料布、树皮瓦、茅草 |
| 隔热层 | 存住热量 | 干草、树叶、碎料填充 |
| 围护层 | 挡动物、隐私 | 编篱、木板、石砌 |

**枝条排 + 填充**是应急建造的主力做法：两面编篱、中间填干叶，一层墙同时拿到挡风和隔热。

## 怎么做

### 编篱填充墙（推荐做法）

1. 立两排平行柱，间距 = 墙厚（20–30 cm）；
2. 细枝在两排柱间横向穿插编织成"三明治"的两面皮；
3. 两皮之间填干树叶、干草——**蓬松填充才隔热**，压实反而导热；
4. 外皮自下而上编，逐层填，最后收顶。

### 石墙 / 土坏（仅在有条件时）

* 石墙干垒（不坐浆）时向内倾斜 1:6（收分），越垒越稳；
* 石墙隔热差、蓄热大——白天吸热夜里放热，冷天不选；
* 场地限制（如需要防视线）才优先考虑。

### 朝向取舍

* 最完整的一面对**主风向**；
* 门侧墙面留出进出与采光，其余面优先封死。

## 注意

* 墙体不承担"防雨"全部任务——顶部与墙的交接缝是漏水主通道，收口交给 [[屋顶]] 与 [[防水结构]]；
* 填充物必须干燥，湿填充物在墙内霉烂、下沉，墙皮随之松散；
* 编篱墙怕火：明火厨房与墙面保持距离，见 [[火]] 的 [[安全用火]]；
* 墙体检查与应急修补沿用 L2 的 [[庇护结构检查]]、[[简单修补]]；本节点讲的是"新建一面墙"。
* 墙体决定了居住体验的大半：风、冷、隐私、防动物都由它承担。编篱填充用同一批细枝和落叶同时解决两层需求——不需要整木、不需要工具，两个下午能围出一间挡风又隔热的小屋。
