# 结构检查与修复

> L2 检查的是"别人的建筑能不能住"，本节点检查的是"自己建的结构还稳不稳"——自建结构的缺陷有固定的模式，按模式查。

## 立即知道

自建结构的三类高频缺陷，按出现概率排：

| 缺陷 | 信号 | 修复方向 |
|---|---|---|
| 接点松脱 | 绑扎下垂、卡口错位 | 重新绑扎、加木楔 |
| 构件变形 | 立柱倾斜、横梁下垂 | 加支撑、换料 |
| 基础沉降 | 整体向一侧歪、柱脚入土 | 垫高柱脚、加底座 |

**触发式检查**比固定周期更有效：大风、暴雨、大雪、地震之后必查；每场天气事件都是一次免费的压力测试。

## 怎么做

### 检查方法

* **看**：退后三步整体看——歪不歪、垂不垂、缝有没有变大（缝上做铅笔标记，下次对比）；
* **推**：对关键立柱施加侧向力，晃动超预期就是支撑不足；
* **听**：受载时吱嘎声集中在哪个接点，哪里就是薄弱处。

### 修复策略（从轻到重）

1. **紧固**：接点松 = 重新绑扎 / 加楔 / 加钉，最便宜，优先做；
2. **加撑**：变形构件加斜撑或辅助柱，让新构件分担荷载；
3. **换料**：朽、裂、虫蛀的构件直接换——修补朽木等于在坏料上继续投资；
4. **降载**：修不住就减少该结构承担的重量（清空阁储、压低屋面），甚至废弃该部分。

### 与 L2 的分工

* 现成建筑的检查与应急修补 → L2 的 [[庇护结构检查]]、[[简单修补]]；
* 自建结构的模式化检查与结构性修复 → 本节点；
* 两者的判断原则一致：**否决项（会塌）不修，降级使用或撤离**。

## 注意

* 修复作业本身有风险：先支撑固定、再动薄弱件——拆掉唯一支撑去"修"是最常见的自伤场景；
* 雨季前做一次全面检查，把问题消在天气来之前；
* 记录修复日期与部位，与 [[简单修补]] 的"标日期"规则一致；
* 超出自建强度的损伤（地基位移、大面积变形）不是修复问题，是撤离问题，见 [[安全]]。
* 自建结构不会突然坍塌，它会先"说话"：接点松、缝变大、声音异常——按模式检查就是听懂这些话，把小缺陷拦在大问题之前。
