# 门窗

> 门窗是墙上故意留的洞——每个洞都要回答三个问题：进出、光线、以及"夜里怎么把它关严"。

## 立即知道

| 开口 | 尺寸底线 | 位置 |
|---|---|---|
| 门 | 够身体进出，宽 ≥ 50 cm | 背风面、朝开阔处 |
| 窗 | A4 纸大小即可 | 高于睡姿视线、可关闭 |
| 通风口 | 拳头大小，常开 | 高处，与门异侧 |

**门不止一个**：条件允许时对侧留应急出口——火灾、坍塌、动物堵门时它是第二条命。

## 怎么做

### 门

* 挡门帘：整片厚布 / 毯子挂门洞外侧上沿，下摆压重——比做门板快十倍；
* 门板：枝条编板或木板，两根横杆固定背面，绳环当把手，斜靠式（外开斜倚）最简单可靠；
* 门框：门洞四周立两柱加一梁，把洞口"锁边"，防止墙体开口处坍落。

### 窗

* 先确认需要再开——窗削弱墙体，冷天小窗优于大窗；
* 覆盖用透明塑料布（采光）或木板（夜间保温），做成可开合的：白天透光、夜里封死；
* 窗的位置配合 [[通风]] 的对流路径：窗在低处是进风口，高处是排风口。

### 夜间关闭的检查

* 睡前把"门帘 / 门板 / 窗盖 / 通风口"四项逐一遍过——这正是 [[基本睡眠环境]] 五查的延伸；
* 门内可动障碍物（木棍顶门）优于复杂的锁。

## 注意

* 门洞开在承重面或墙体最长边中央时，开口两侧必须加固立柱；
* 透明塑料布窗冬天结露滴水，下方不要放寝具与纸品；
* 应急出口平时也检查可达——堆了物资的出口等于没有；
* 城市住宅原有门窗的加固（防风、防入侵）归 [[安全]]，本节点讲自建结构的开口。
* 门窗是结构上最弱、使用上最频繁的部分：冷空气从门缝进、雨水从洞口流、风险从开口来。把洞口的位置、锁边和夜间关闭想清楚，一间自建庇护才从"有壳"变成"能住"。
