# 绳结

> 不需要会一百种结——会五六个，覆盖建造与生活里 95% 的用绳场景。

## 立即知道

按用途记结，不按名字记：

| 用途 | 结 | 特点 |
|---|---|---|
| 固定在桩、树、环上 | 系木结（拴马结） | 受力不滑，一抖即解 |
| 不让绳头散、绳圈不脱 | 八字结 | 比单结可靠，解得开 |
| 两根绳接长 | 渔人结 / 双渔人结 | 细绳接绳最可靠 |
| 绳中做固定圈（套桩） | 称人结（布林结） | 受力不勒死，解得开 |
| 捆扎平行的木料 | 剪式缠绕（见 [[木材连接]]） | 建造主力 |
| 收紧后不再动 | 双半结加固 / 死结收尾 | 越拉越紧 |

## 怎么做

### 学法

* 每个结闭眼打 10 次，才算会——黑暗里、雨里、着急时只有手感能靠；
* 打完必做**两个测试**：用力拉（不该滑的不滑）、反向一抖（该解的解得开）；
* 湿绳、冻绳、旧绳全部按"降一级可靠度"使用：能双结不单结。

### 建造里的搭配

* 拉线固定：系木结 + 中段双半结收紧；
* 帐篷风绳：活结一头留调节扣，白天松晚上紧；
* 吊挂物品：称人结做圈，避开尖角。

## 注意

* **解不开的结不是好结**——除非明确决定"永久固定"，永远选解得开的方案；
* 尼龙绳表面光滑，单结会滑脱，收尾必须加半结锁口；
* 绳子磨损检查：起毛、断股、发硬的部分裁掉，弱段不在受力段使用；
* 高处悬挂、承重的结，建好后先挂重测试再正式使用。
* 绳结的价值在"可逆的连接"：钉死的拆不掉，绑扎的随时调整。五六个结覆盖大部分场景，建造、捆扎、拖曳都多一条手段。
