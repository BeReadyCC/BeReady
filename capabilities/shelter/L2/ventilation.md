# 通风

> L1 的 [[防风]] 挡外面的风，通风保里面的空气——两者方向相反，但住人的空间必须同时成立。

## 立即知道

通风要排走四样东西：

| 对象 | 来源 | 不通风的后果 |
|---|---|---|
| 一氧化碳与燃烧废气 | 火炉、炭火、燃气 | **致死**，最优先 |
| 水汽 | 呼吸、做饭、晾晒、地面返潮 | 结露、霉变、寝具潮湿 |
| 异味与污浊空气 | 人体、排泄、垃圾 | 影响判断与睡眠 |
| 热空气淤积 | 高温天气 | 中暑风险 |

## 怎么做

### 布置对流

* 一进一出：**低处进风口 + 高处排风口**，靠温差形成自然对流；
* 进风口不要正对人睡觉的位置——吹整夜的穿堂风比闷更伤人；
* 封闭小空间（帐篷、地窖式房间）哪怕冷天也必须留一个拳头大小的通风口；
* **有明火的房间，口要更大**：进风口加排风口的总面积，不小于房间地面面积的 **五十分之一**，而且要一低一高分别开在两侧，让空气有进有出；烧炭的封闭小屋是致死率最高的场景，别把两个口开在同一高度。

### 与用火绑定

* 只要用火（取暖、做饭、照明），通风就是**强制项**不是选项，具体规则见 [[火]] 的 [[安全用火]]；
* 睡觉前确认：火已熄灭或炉具密封完好，通风口没有被雪、布、行李堵住。

### 控湿

* 晾湿衣物集中一处、靠近通风口，不要摊在睡觉区；
* 做饭的蒸汽用盖子压、用排风带走；
* 墙面已结露：擦掉 + 拉开家具与墙的距离 + 加大通风。

## 注意

* **通风与保温不矛盾**：留通风口损失的热量远小于湿气造成的损失——湿被子夜里带走的潜热比缝隙风多得多；
* 一氧化碳无色无味，"感觉闷"时往往已经超标——嗅觉判断不了 CO，只能靠通风制度和位置安排；
* 夏天通风换成防虫：通风口加纱网，方向不变；
* 系统化的通风设计（烟道、机械排风）是 L4 的 [[通风系统]] 主题。
* 密闭空间住人、用火、做饭之后，就变成四种污染的积累器。通风是在"保温 / 防风"和"空气安全"之间取最小代价的平衡——CO 中毒几乎全发生在"觉得冷所以全封死"的夜里。
