# 庇护结构检查

> L1 解决"今晚住在哪"，L2 从"能连续住人"开始——而连续住的前提是知道这个空间还有哪些隐患。

## 立即知道

一个空间从"临时躲一下"变成"连续住几天"，要先过五类检查：

| 检查类 | 看什么 | 失格信号 |
|---|---|---|
| 结构 | 裂缝、变形、下沉、悬空构件 | 新鲜裂缝贯穿、门窗卡死变形 |
| 水患 | 屋顶渗痕、墙面水线、地面返潮 | 多层旧水线、霉斑成片 |
| 电气 | 插座、电箱、裸露线路 | 烧痕、焦糊味、水泡 |
| 燃气 | 阀门、软管、气味 | 臭鸡蛋味——立即撤离，见 [[火]] 的 [[燃气安全]] |
| 通道 | 出口数量、通道宽度、杂物 | 只有一个出口且被堵 |

## 怎么做

### 检查顺序

1. **先外后内**：外墙裂缝、屋檐松动、落水管、周边悬空物（广告牌、花盆）；
2. **再由入口深入**：地面 → 墙面 → 天花板，由下往上看一遍；
3. **最后查系统**：水、电、燃气，各自单独验证，不凭"应该没事"。

### 记录

* 把发现的问题按"**会塌 / 会漏 / 会电人 / 会中毒 / 挡逃生**"五类登记；
* 每类只记三样：位置、严重度（能不能住）、要动手的活；
* 余震、暴雨、大风之后**必须重查一遍**——检查结果有时效。

### 判断"能不能住"

* 结构和水患是**否决项**：有贯穿裂缝或成片霉斑水线，换地方，不修补；
* 其余三类是可以动手解决的问题，见 [[简单修补]]。

## 注意

* 老旧建筑查承重墙和楼板的裂缝方向——斜向贯穿缝比表面裂纹严重得多；
* 检查电气前先断总闸，湿手不碰任何开关；
* 有燃气味的空间**不要开灯、不要打火**，先开门窗、撤到室外；
* 结构性大问题（承重裂缝、地基沉降）不是 L2 修补能解决的，按 [[安全]] 的原则优先撤离。
* "临时避护"允许带病运转，因为只住一晚；"稳定居住"的每次睡觉、用火、用电都在放大未发现的隐患。检查是把"不知道的风险"变成"登记在册的活清单"。
