# 简单修补

> 修补的门槛不在手艺，在判断——先分清"能修的"和"不该修的"，剩下的多数用胶带和绳子就能对付。

## 立即知道

先做分流，两类东西不进修补队列：

| 不修 | 原因 | 替代动作 |
|---|---|---|
| 结构性问题（承重裂缝、下沉） | 修不住，风险继续累积 | 换房间、撤离，见 [[庇护结构检查]] |
| 涉及电气与燃气系统的损坏 | 非专业操作会放大风险 | 断电断气，别自己碰 |

能修的典型：漏雨的顶、松动的门、破的塑料布、卡死的窗、松脱的把手。

## 怎么做

### 随身修补弹药

| 材料 | 用途 |
|---|---|
| 宽防水胶带 | 堵漏、补塑料布、固定——万能首选 |
| 绳子 / 伞绳 | 捆扎、悬挂、拉线固定 |
| 铁丝 | 承力捆扎、悬挂重物 |
| 玻璃胶 / 油灰 | 封缝、固定小型物件 |
| 螺丝刀 + 螺丝几颗 | 紧固松脱件 |
| 备用塑料布 | 苫盖、补洞 |

### 通用步骤

1. **看清坏法**：是松了（紧固）、裂了（填补）、破了（覆盖）、还是缺了（替代）；
2. **选最小方案**：胶带能解决的不上螺丝，绳捆能解决的不起架子；
3. **修完测试**：压一压、拉一拉、浇一点水——修补不当（尤其是高处物件）会二次伤人。

### 常见三例

* 塑料布破洞：内侧贴胶带补，撕拉方向与受力一致；
* 门变形关不上：先查是铰链松（紧固）还是框变形（刨边或垫片）；
* 窗玻璃碎了：塑料布 + 木板从内侧封死，边缘全部胶带压边。

## 注意

* **临时修补要标日期**——胶带撑不过一个雨季，到期重查，别让应急措施伪装成永久方案；
* 高处修补（屋顶、外墙）遵守 [[防水]] 的安全条目：不独自上、恶劣天不上；
* 修补材料本身是可燃物，明火房间里的胶带、塑料布远离火源；
* 修不好就降级使用：修不住的房间封掉，缩小生活范围，见 [[生活区域划分]]。
* 稳定居住一半是"发现问题"，一半是"动手处理"。修补的价值不在恢复原状，而在**用最小代价维持空间可住**——能撑过雨季的胶带补丁，比等一个等不来的专业维修实在。
