# 药品储备

> 药是消耗品，用一粒少一粒。囤对、存对、先到期先用，才能撑过最长的断供。

## 囤什么（按优先级）

1. 慢性病维持药（降压 / 降糖 / 胰岛素）—— 断了立刻要命，最先囤足。
2. 急用药：退烧止痛、止泻补液、抗过敏、外用消毒（碘伏 / 酒精 / 高锰酸钾）、烫伤膏。
3. 抗生素：谨慎囤、谨慎用，只作细菌感染的备用药。
4. 维生素：缺菜时补基础。

## 怎么存

* 阴凉、干燥、避光。多数药怕潮怕热，别放厨房、窗边。
* 分装时保留原标签，或写清药名、用途、剂量、日期。
* 片剂变软变潮、胶囊粘连、液体浑浊 = 变质，弃。

## 有效期

* 到手先标到期日，先到期先用。
* 过期药不吃，尤其抗生素和液体制剂。
* 每 1～2 个月清一次：按到期日排一遍，快到期、变色结块的挑出来先用掉；同时记下哪几种快见底，下次有机会先补这几样。

## 暴露意识

* 缺药时药品是紧俏资源，储备位置要分散、不起眼，别把全部药堆在一个显眼处。
* 分装成小份藏于不同位置，降低一次性全部损失的风险。

## 注意

* 储存处不做明显标识；每 1～2 个月开箱看一次有没有受潮、虫蛀、瓶盖松，片剂保持密封。
