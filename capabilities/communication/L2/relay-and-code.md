# 人力传递与约定

> 没设备、没信号时，最稳的是人跑腿。先把会合点、暗号、时间定好，消息才接得上。

## 会合点

* 提前约定多个备选会合点，主点出事就转备用点。
* 会合点选好找、好守、不显眼的地方，见 [[安全路线]]、[[撤离]]。
* 到点没人，按约定等够时间再撤，别乱跑。

## 暗号与标记

* 只有自己人懂的暗号：几声哨、什么摆法、什么话尾。
* 标记样式见 [[信号与标记]]；暗号定期换，防被外人摸准。
* 约定好「安全 / 危险 / 等我」各用什么信号。

## 信使

* 选可靠、认路、体力好的人往返传递，见 [[行进与定位]]。
* 固定时间、固定地点交换信息，错过等下一轮。
* 传的话要短：谁、在哪、做什么、何时回。

## 低调

* 传递路径、人员、内容别太招眼，避免留下可追溯的痕迹。
* 信使走小道、避大路，见 [[不迷路的习惯]]。
* 写下来的字条用完即毁，别留物证。

## 注意

* 信使失联别慌，按约定等满时限再启动备用方案。
* 暗号泄露立刻换，见 [[群体行动安全]]。
* 一次只传一件事，太长容易传错、记错。
