# 通信

> 崩溃后没有电话网、没有基站、没有互联网。消息只能靠你亲手传、亲手收——为了获取信息、判断局势、跟自己人协调，不是为了找人来救。

通信的前提是「没网没电也能用」。本能力只写信息传递与获取：怎么跟同伴联络、怎么标路线标位置、怎么听外界动静、怎么靠人跑腿。信号、烟、火光、声音都会暴露位置，需要低调时收着用。

## Level 划分

| Level | 能力目标 | 核心知识 |
|---|---|---|
| L1 · 立即可用 | 当天就能用，手头现有物品（镜/金属/哨/火/收音机对讲机），不需要额外制作 | 3 |
| L2 · 需要条件/经验 | 需要一定设备、约定经验或观察判断：听广播辨局势、人力传递与暗号 | 2 |
| L3 · 进阶方向（未展开） | 长距离通信、简易无线电制作 | 0 |

判据：L1 当天就能用、靠现成物；L2 需要设备/约定/判断力；L3 需要更长距离和自制能力。

## L1 · 立即可用

### 能力目标

没网没电的当天，用手边现有物品跟同伴联络、标记路线和位置、用无线电听和说。信息贵在「对得上、不暴露」。

### 核心知识

* [[通信的基本逻辑]]
* [[信号与标记]]
* [[无线电基础]]

### 不够怎么办

* 现成信号传不远、看不清局势 → 进入 L2（[[获取与判断信息]]）。
* 没设备、信号用不了、需要异地协调 → 进入 L2（[[人力传递与约定]]）。
* 同伴分散、需要稳定长距联络 → L3 的 [[长距离通信]]（方向）。

---

## L2 · 需要条件/经验

### 能力目标

靠收音机短波听外界、靠观察环境判断局势、靠信使和暗号跟分散的同伴交换信息——消息要交叉验证，别轻信单一来源。

### 核心知识

* [[获取与判断信息]]
* [[人力传递与约定]]

### 不够怎么办

* 普通无线电距离不够、需要更远联络 → L3 的 [[长距离通信]]（方向）。
* 没有设备、想自己造简易电台 → L3 的 [[简易无线电制作]]（方向）。

## 待理清的问题

* **「信号与标记」与 [[火]] 的边界**：本能力写「用烟用火光传信」，点火与熄灭的具体操作归火章节，正文中引用不重造。
* **收音机广播的定位**：L2 写「听广播获取外界动静」，但广播只是来源之一、不能当唯一真相，与「不依赖官方广播」的红线如何统一表述，需在节点内明确「只取信息、交叉验证、不盲信」。
* **暴露与低调的统一口径**：火光、烟、声音、无线电都会暴露，已分散在多个节点写「需要低调时收着用」，是否要在 [[通信的基本逻辑]] 集中一条「暴露总原则」供各节点引用。
* **[[长距离通信]] 是否建节点**：目前仅方向，涉及中继/地形/时段，待确定内容深度再展开。
