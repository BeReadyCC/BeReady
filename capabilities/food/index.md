# 食物

> 在无法依赖正常食品供应时，获得、保存、处理并持续获得食物的能力。

食物解决的不只是“今天吃什么”。

当商店、物流和正常供应持续中断时，需要逐渐回答：

* 手上的食物还能吃多久？
* 哪些已经不能吃了？
* 怎样在条件变差的情况下把它做熟、做得安全？
* 怎样让有限的食物撑得更久？
* 吃完以后从哪里继续获得？
* 怎样从一次性的储备，变成可以持续产出的来源？

## Level 划分

| Level | 能力目标 | 核心知识 |
|---|---|---|
| L1 · 基本进食 | 用手上已有的食物，安全地吃、合理地分，尽量撑得更久 | 9 |
| L2 · 保存与管理 | 用储存、密封、低温、干燥等手段延长已有食物的可用时间 | 8 |
| L3 · 获取与替代 | 主动在环境中寻找、采集、捕获食物，并做基础处理 | 5 |
| L4 · 持续食物来源 | 建立可以持续产出的食物来源（尚未展开） | 0 |

Level 的判断标准不是“知识难不难”，而是**它在能力发展中处于什么位置**：

* L1 的每个节点，都是食物供应中断后当天就能用、并且不需要额外材料的；
* L2 的节点需要一定的容器、材料、能源或条件；
* L3 的节点需要主动外出获取；
* L4 才是自己建立食物生产。

## L1 · 基本进食

### 能力目标

能够利用当前能够获得的食物，安全地维持基本进食。

L1 首先解决：

> **有东西的时候，能够安全地吃；东西不多的时候，知道先吃什么、怎么分。**

首先要能够：

* 知道手上有什么、大概还能撑多久
* 判断哪些食物已经不能吃
* 在条件变差时把食物做熟、做得安全
* 把有限的食物分配得合理
* 减少因为食物引起的疾病和浪费

### 核心知识

* [[清点现有食物]]
* [[变质判断]]
* [[可食与不可食]]
* [[食物安全]]
* [[基本烹饪]]
* [[食物分配]]
* [[避免食物浪费]]
* [[饮食与饮水]]
* [[断电后的食物]]

### 不够怎么办

当手上的食物明显不够，或现有条件已经无法保证安全时，进入 L2。

## L2 · 保存与管理

### 能力目标

当新的食物无法稳定获得时，能够延长已有食物的可用时间，并把食物管理变成一个有计划的过程。

核心转变：

> 从“吃掉食物”进入“管理食物”。

### 不够怎么办

当现有储备结构已经建立起来、但总量仍然不够时，进入 L3，开始主动向外获取。

## L3 · 获取与替代

### 能力目标

现有储备不足时，能够通过环境、已有资源和简单工具获得更多食物，并对这些食物做基础处理。

### 核心知识

* [[野外可获得食物]]
* [[安全识别食物]]
* [[采集]]
* [[捕获]]
* [[基础加工]]

这里开始明显依赖：

* [[水]]
* [[火]]
* [[工具]]
* [[卫生]]

因此这些知识应通过 Wikilink 连接，而不是重复建立相同内容。

### 不够怎么办

当储备和野外获取都已经跟不上消耗，唯一可持续的出路是自己生产——这件事已拆成两个独立能力：地里种出来的归 [[种植]]，动物、加工、整年的来源规划归 [[生产]]。

## L4 · 持续食物来源（已由 [[种植]] 与 [[生产]] 承接）

### 能力目标

核心转变：

> 从"寻找食物"进入"生产食物"。

**这一层不再由食物章节自己承载**（2026-09-19 定案）：食物章节到「获取 + 保存 + 基础加工」为止，往后是两套独立能力，各自有完整索引：

## 继续探索

食物能力的主线是：

> **安全进食 → 保存已有食物 → 主动获取 → 持续生产**

农业体系、大规模畜牧、工业食品生产等更高复杂度内容可以继续向后发展，但不作为第一阶段的核心入口。

### 深度复核（2026-09-19，048 L2 / L3 全部通读）

### 待理清的问题

* **「干燥食品」已决定并入 [[食物脱水]]**，L2 核心知识由 9 个调整为 8 个。理由：[[食物脱水]] 已经覆盖"自制干燥"的全部内容，而"干货的保存"已经由 [[食物防潮]] 与 [[食物防虫]] 承担，再单独立一个节点只会造成三处重复。如果仍希望保留这个名字，它的唯一定位应是"已有干货的识别、复水与使用"——但那属于 L1 的进食范畴，不属于 L2 的保存。
* ~~**[[食物轮换]]（L2）与水的 [[长期储水与轮换]]（L3）层级不对称**~~ **已定案（2026-09-19）**：不强行统一——两者性质不同。[[食物轮换]] 管的是**同一批食物内部的取用顺序**（先存的先吃），属"保存与管理"的日常动作，落 L2；水位那个节点管的是**长期储备的整个系统**（备多少、撑多久、多久换、藏哪里），天然带长期规划性质，落 L3。层级差异反映的是能力复杂度不同，不是口径不一致。
* ~~[[食物分配]]、[[避免食物浪费]]、[[饮食与饮水]] 边界需要再确认~~ **已定案（2026-09-19，048）：分工清楚，不合并。** 三者回答的是三个不同的问题——[[食物分配]] 管"**分给谁、分多少**"（人群优先级 + 按天定量 + 进食节奏，防止"饿三天、饱一天"）；[[避免食物浪费]] 管"**怎么让它不被糟蹋**"（消耗顺序 + 一次做多少 + 边角料去向）；[[饮食与饮水]] 管"**缺水时吃什么种类**"（少盐 / 少蛋白 / 少干）。唯一的接触面是"先吃易坏的"这条顺序，已由 [[食物分配]] 用一句指向 [[避免食物浪费]]，没有两处各讲一遍。
* ~~[[食物储存]]（L2 总览）与 L2 各具体手段之间，需要明确谁是入口、谁是细则~~ **已定案（2026-09-19，048）：现有写法即为正确分工，不动。** [[食物储存]] 是**入口与判断层**——先按"每样食物最怕什么"归类（四类敌人：水 / 温度 / 空气 / 生物），再决定用哪类手段，另有位置选择与记录轮换；[[密封储存]]、[[食物防潮]]、[[食物防虫]]、[[低温保存]]、[[食物脱水]] 是**五种手段各自的细则**。判断在前、手段在后，链接方向已经是这样。
* [[野外可获得食物]]（能获得什么）、[[安全识别食物]]（能不能吃）、[[采集]]（怎么获取）、[[基础加工]]（怎么变成能吃）四者的边界**已按此分工实现并通过 048 通读复核**，维持。
* ~~[[安全识别食物]]（L3）与 [[可食与不可食]]（L1）存在部分重叠~~ **已定案（2026-09-19，048）：不合并，按场景分而非按知识类型分。** [[可食与不可食]] 面向**手上已有的、常见的**食物——哪些本身带毒、哪些必须彻底做熟、哪些部位不能吃；[[安全识别食物]] 面向**野外不认识的物种**——三重确认、红线清单、"只采确定认得的短名单"。两者都写了"野生蘑菇不要采"，是**有意重复**而非冗余：这是全库致死风险最高的一条，两个入口各留一次值得。
