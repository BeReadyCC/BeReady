# 食物储存

> 没有正常供应链的条件下，让食物保存得比常温更久。

## 立即知道

食物变坏基本来自四件事：

| 原因 | 表现 |
|---|---|
| 水分 | 受潮、发霉、结块 |
| 温度 | 变酸、发酵、油脂哈喇 |
| 空气 | 氧化、变味、虫卵孵化 |
| 生物 | 虫蛀、鼠咬、霉变 |

对应的手段也只有四类：**干燥、低温、密封、防虫**。

所以储存的第一步不是找容器，而是先弄清楚每一样食物最怕什么。

## 怎么做

### 按“最怕什么”分类

| 食物 | 主要敌人 | 主要手段 |
|---|---|---|
| 米、面、谷物 | 潮、虫 | 干燥 + 密封 + 防虫 |
| 食用油 | 光、热、氧 | 避光、阴凉、密封 |
| 坚果、干果 | 氧、潮、虫 | 密封、低温 |
| 罐头、真空包装 | 高温、冻裂、碰撞 | 阴凉、不挤压 |
| 新鲜果蔬 | 失水与腐烂 | 低温、通风、分开 |
| 肉、禽、鱼 | 细菌 | 低温、干燥、盐腌、烟熏 |
| 糖、盐、蜂蜜 | 潮 | 密封（本身几乎不会坏） |

### 选择位置

好的储存位置通常是：

* 阴凉、干燥、避光、温度波动小；
* 离地和离墙一段距离（防潮、防鼠）；
* 不与燃料、清洁剂、农药放在一起（串味与污染）。

### 记录与轮换

储存不是堆起来就结束。要有清单和日期，并按顺序消耗，见 [[食物轮换]] 与 [[清点现有食物]]。

## 注意

* **不要把同一类食物全部放在一个地方。** 一次水浸、一次虫害或一次火灾就能清空全部储备。
* 不要用装过化学品、燃料的容器装食物，即使洗过。
* 玻璃罐、金属桶比塑料袋更能防虫防潮，见 [[密封储存]]。
* 粮食的霉变（黄曲霉毒素）不能通过加热去除，发霉就整批处理，见 [[食物防潮]]。
* 储物区要保持通风。潮湿的储藏间比温度稍高的地方更伤食物。
* **储存位置也是暴露面。** 集中的、显眼的食物堆会暴露储备的规模，尽量分散、不起眼地放。
