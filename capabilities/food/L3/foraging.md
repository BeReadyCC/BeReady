# 采集

> 好的采集不是“找到什么采什么”，而是沿着固定路线，重复收获确定的东西。

## 立即知道

采集的效率不取决于眼睛多尖，取决于**有没有已知的点位和固定的路线**。

第一次到一个地方，能采到的东西通常很少；第二次、第三次回到同一片区域，收获会明显变多——因为你知道哪棵树下有坚果、哪片湿地有可食的根茎、什么时间成熟。

所以采集的第一件事是**建立点位记录**，不是马上装满袋子。

## 怎么做

### 出门前

带上：

* **手套**——防刺、防接触性皮炎；
* **分装的袋子或容器**——不同种类分开装，避免互相污染和串味；
* **刀或剪**——切割而不是连根拔；
* **记录本或手机**——记点位、时间、种类；
* **水和盐**——采集是体力活动，见 [[饮食与饮水]]。

### 一次只做一件事

每次出门只针对**一到两种**已经确认认识的东西。

同时找很多种会导致：判断出错、处理混乱、回到营地后分不清哪袋是什么。分不清的后果就是全部丢掉，甚至误食。

### 采集原则

* **只采认识的**，见 [[安全识别食物]]。
* **留大头**：采 1/3，留 2/3。连根拔、整片清空会让这片区域明年不再产出。
* **不采最差的**：已经萎蔫、有虫孔、发霉的不要，救不回来还会带来霉菌毒素。
* **不采边角料**：公路边、农田边、果园边、工厂和矿区附近一律不采。

### 采什么最划算

按“产量 ÷ 处理难度”排序：

| 类型 | 说明 |
|---|---|
| 果实、坚果 | 能量密度高，处理简单，优先 |
| 地下根茎、块茎 | 热量高，但需要挖，耗体力 |
| 嫩叶、嫩芽 | 量大易得，但热量低，见 [[野外可获得食物]] |
| 水生植物 | 需注意水体是否污染、是否有寄生虫 |
| 菌类 | 风险最高，收益不确定（见下） |

### 回到营地后立刻处理

1. 分类摊开，不要堆在一起闷着；
2. 用干净水清洗，见 [[水]]；
3. 该焯水的焯水，见 [[基础加工]]；
4. 当天吃不完的，按 [[食物脱水]] 或 [[食物储存]] 处理；
5. **任何拿不准的一律丢掉**，不要“先放着再说”。

## 注意

* 潮湿季节的采集要防蜱虫和蚊虫，穿长袖长裤，回来后检查身体。
* 不要在同一片区域同时做“采集”和“设陷阱”，会互相干扰，见 [[捕获]]。
* 采集路线要告诉同伴。独自进入不熟悉的区域时，记录进入和返回时间。
* **采集会留下痕迹**：被拨开的草丛、踩出的路、采空的植株都会暴露你的点位和路线。需要低调时，换着地方采，不固定走同一条路，不留大片采空痕迹。
* 采集的产出靠的是信息，不是运气。同一片林地，知道点位的人两小时能采满一袋，不知道的人走一天也采不到多少——所以把时间花在记录和确认上，比花在走路上回报更高。
