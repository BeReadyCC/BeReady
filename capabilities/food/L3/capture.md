# 捕获

> 捕鱼和设陷阱的产出，通常远远比不上采集；先做投入产出比最低的那件事，是最常见的浪费。

## 立即知道

按“成功率 ÷ 投入”排序，现实中最有效的顺序是：

| 方式 | 现实评估 |
|---|---|
| 捕鱼（网、笼、钓） | 效率最高。水体里生物密度大，工具可重复使用 |
| 昆虫 | 最容易获取，蛋白质效率最好，但接受度低 |
| 小型哺乳动物（陷阱） | 中等。需要找到兽径，且设好之后要等 |
| 鸟类 | 低。视觉和嗅觉都灵敏，很难接近 |
| 大型动物 | 极低。需要武器、技巧、体力和多人协作 |

**狩猎在绝大多数应急场景里是低效选项。** 如果没有枪和长期训练的狩猎经验，把时间投在捕鱼、设陷阱和采集上回报更高。

## 怎么做

### 捕鱼

* **鱼笼 / 倒须笼**：用竹子、树枝、铁丝编成。放在有水流或鱼道的位置，入口做成越进越深的结构。可以全天挂着，是投入产出比最好的方式。
* **刺网 / 围网**：效率高，但需要绳线材料。
* **钓**：钩、线、竿都可以自制。关键是**找对位置**——回水湾、水草边、桥墩下、入水口，比换什么饵都重要。
* **饵**：昆虫、蚯蚓、面团、内脏。
* **筑坝 / 围堰**：在小溪上做拦截，把水排掉取鱼。耗体力，但小水体效果好。

### 陷阱

* 陷阱要设在**兽径上**——动物有固定的通行路线，通常在草丛里能看到被压出的小路。
* 常见形式：圈套（套腿部）、落石压板（小型动物）、箱笼（可用倒须结构让动物进得去出不来）。
* 陷阱要**每天检查**。动物被长时间困住会死亡腐烂，既浪费又可能传播疾病。

### 昆虫

* 蛋白质效率最高的来源。蝗虫、蟋蟀、蝉、白蚁、水生幼虫都可食。
* **必须彻底加热**，并且要**去翅、去足、去内脏**（部分种类）。
* 不要吃：颜色鲜艳的、有刺毛的、气味刺鼻的、以腐肉或粪便为食的种类。
* 对甲壳类过敏的人，吃昆虫也可能过敏——第一次少量试。

## 注意

* **陷阱会伤人。** 不在有人可能经过的地方设置；每个陷阱都要有标记和位置记录。
* **处理野生动物是高风险行为。** 啮齿类和野兔可能携带鼠疫、兔热病、出血热；狐狸、狗科可携带狂犬病；野猪、鹿可能携带布鲁氏菌、结核、寄生虫。处理时必须戴手套、洗手、避免体液接触，见 [[卫生]]。
* 动物死亡后要**尽快放血、去内脏、彻底加热**。肉一旦腐败，毒素无法通过再加热去除。
* 不要捡拾**已经死掉、来源不明**的动物。看到的死亡时间不可靠，且可能死于疾病。
* **鱼笼、陷阱本身就是暴露痕迹。** 放在显眼处会暴露你的活动范围和规律，尽量选隐蔽点位、不固定在同一处。
