# 基础加工

> 加工只解决“能不能安全吃、能不能吃得下去”，不解决“这东西本来就有毒”。

## 立即知道

加工的目的有五个：

* **去毒**——去掉或破坏天然毒素；
* **去苦、去涩、去酸**——让本来难以下咽的东西能吃；
* **杀菌、杀寄生虫**——加热是唯一同时做到这两点的手段；
* **提高消化率**——破坏细胞壁、钝化酶，让营养更容易吸收；
* **延长保存**——脱水、盐腌、发酵。

要提前记住的一条边界：**加工不能改变“不认识就别吃”**。去掉毒素的前提是你已经知道毒在哪、怎么去；不知道的就不要加工，直接丢弃，见 [[安全识别食物]]。

## 怎么做

### 按问题选方法

| 要解决的问题 | 做法 | 典型对象 |
|---|---|---|
| 泥、虫、虫卵 | 反复清洗、搓洗、盐水浸泡 | 叶菜、螺、贝、水生植物 |
| 草酸、生物碱、苦味 | 沸水焯烫后**弃水**，可重复 1～2 次 | 竹笋、蕨类、部分野菜 |
| 氰苷 | 长时间浸泡并**多次换水**，再彻底加热 | 木薯、部分豆类、苦杏仁 |
| 凝集素、酶抑制剂 | 充分加热至完全熟透（豆浆要真正煮沸） | 豆角、豆浆、豆类 |
| 寄生虫、细菌 | 彻底加热至中心温度足够高、时间足够长 | 鱼、肉、螺、蟹 |
| 需要延长保存 | 脱水、盐腌、烟熏、发酵 | 肉、鱼、蔬菜 |

### 处理的固定顺序

1. **先去不能吃的部分**：壳、皮、内脏、鳃、肠、芽和青皮——毒素和污染物往往集中在这里。
2. **再洗**：用干净水彻底洗，见 [[水]]。
3. **再焯水或浸泡**：这一步是去苦去毒，水要倒掉，不要拿去做汤。
4. **最后加热**：彻底做熟，见 [[基本烹饪]]。
5. **分装保存**：吃不完的按 [[食物脱水]] / [[密封储存]] 处理。

反过来做（先加热再去皮、先煮再用焯过的水）会把已经溶出的毒素又带回去。

### 盐腌与发酵

* 盐腌靠降低水分活度抑菌，需要盐量足够；盐不够的“半腌”反而危险。
* 发酵需要干净的容器、适当的温度和无氧条件。
* 两者都是高风险操作，条件不具备时不要尝试。**缺氧环境下的腌制食品存在肉毒杆菌风险**，必须充分加热后食用。

## 注意

* **耐热毒素无法通过加工去除。** 米酵菌酸（久泡木耳、变质发酵米面）、黄曲霉毒素（发霉粮食）、鹅膏毒肽（剧毒蘑菇）、贝类毒素都不怕加热。这类情况只有一个处理方式：丢弃。
* 加工用的所有器具、砧板、手都要保持干净，生熟分开，见 [[食物安全]]。
* 浸泡、焯水都要用**干净水**。用脏水加工等于重新污染。
* 加工后仍然不认识的东西不要吃。加工不改变物种。
* 加工过程有时间成本。如果处理一样食物的时间超过它能提供的能量，就不要处理它。
* 判断加工管不管用，先分清毒素是哪类：草酸、生物碱、氰苷、凝集素大多能靠高温或浸泡去掉；米酵菌酸、黄曲霉毒素、鹅膏毒肽这类稳定小分子，加热到 100 °C 也不分解。
