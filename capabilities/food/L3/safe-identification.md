# 安全识别食物

> 识别只有两个结果：确定能吃，或者不吃。没有“大概能吃”。

## 立即知道

先记住几条**不能用来判断**的方法，它们都不可靠：

| 流传的做法 | 为什么不能用 |
|---|---|
| 动物吃过就没事 | 动物的代谢和人不同。鹿、松鼠能吃的东西对人可能有毒 |
| 银针、大蒜、米饭试毒 | 只对极少数特定毒素有反应，对植物毒素基本无效 |
| 煮过就没事 | 只能破坏部分毒素。耐热毒素（如米酵菌酸、鹅膏毒肽）加热无效 |
| 试吃一点点看反应 | 有些毒素有数小时到数天的潜伏期，发作时肝肾已经受损，不可逆 |
| 长在干净地方就没毒 | 生长环境与是否含毒无关 |
| 苦的/难闻的就有毒 | 剧毒的鹅膏菌气味清香、味道不苦 |

**试吃法是历史上真实用过的方法，也是造成死亡最多的方法。** 不要用它。

## 怎么做

### 三重确认原则

只有当一棵植物 / 一朵菌同时满足下面三条，才考虑食用：

1. **多个独立特征都对**：叶形、叶序、茎的剖面、气味、根系、花、果实、绒毛、乳汁——不能只看一条。
2. **有明确的对照**：和已经确定认识的实物或可靠资料逐一比对过，不是凭印象。
3. **自己 100% 确定**：心里有任何“可能是别的东西”，就判定为不吃。

### 绝对红线清单

见到以下特征，直接放弃，不做进一步判断：

* **菌类**：白色伞面 + 菌托（基部杯状膜）+ 菌环（菌柄上的裙边）三者相近的组合；菌褶白色且孢子印白色的大型伞菌；任何一处与已知剧毒种相似的。
* **植物乳汁**：折断后流出乳白色汁液（大戟科、部分夹竹桃科）。
* **伞形科**：长得像野芹菜、野胡萝卜、香菜、芹菜的野生植物——毒芹等剧毒种就在这一科，仅凭外观几乎无法区分。
* **不明豆科种子**：含氰苷和凝集素，未彻底加热有风险。
* **苦杏仁气味的种子**：蔷薇科果核里的仁（苦杏仁、桃仁、苹果籽）。
* **发芽、变青、发苦的薯类**：龙葵素集中在芽和青皮里，见 [[可食与不可食]]。
* **不明贝类与藻类**：赤潮期毒素富集，加热无法去除；有害藻类与食用藻外观难分。
* **不认识的真菌，一个都不采。**

### 摸也要小心

有些植物不是吃出问题，而是碰到就出问题：

* 漆树科（毒漆藤类）会引起严重接触性皮炎；
* 大戟科、荨麻的汁液会灼伤皮肤。

处理不认识的植物时戴手套，不要揉眼睛，处理完洗手。

### 把清单反过来记

对你更有用的不是“能吃什么”，而是**“这一片区域里，我确定能认出的那三五种是什么”**。

把这个短名单背下来，只采名单里的东西，安全性会高得多。

## 注意

* 婴幼儿、老人、孕妇、有肝肾疾病的人，对毒素更敏感，野外食物的门槛要更高。
* 第一次吃某种野生食物，即使已确认种类，也要**少量、单独吃**，观察半天再正常食用，以排除个体过敏。
* 蘑菇中毒**没有家庭解毒办法**，误食几乎没有回头路——所以底线是不采、不吃。
* 同一种植物在不同生长阶段、不同部位，毒性可能不同（如嫩芽可食、老叶有毒）。
* 植物毒素和菌类毒素往往没有解药，且损伤不可逆。安全识别的核心不是“学会辨认更多东西”，而是**养成只吃确定食物的习惯**。
