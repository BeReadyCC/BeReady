# 伤口感染与恶化

> 伤口处理不好，感染会从「小伤」变成「要命」。窗口很短，每天都得看。

## 立即知道

**红、肿、热、痛加重、流脓、发热 = 感染**。

从受伤到失控，可能只要**一两天**。「再观察一天」是最危险的决定。

## 怎么认（按出现顺序）

1. 伤后 **24～48 小时**开始：伤口周围一圈发红，按上去痛；
2. 红晕**往外扩**——用炭笔在皮肤上画出边界，第二天比对，扩大就是恶化；
3. 局部发烫、跳痛、肿起来；
4. 有脓：黄、绿、灰白，有臭味；
5. 全身反应：发烧、寒战、没劲。

两个必须立刻认出来的警报：

* **红线警报**：伤口向心方向出现一条红线往上爬，沿线淋巴结（腋下、腹股沟）肿痛 → 感染沿淋巴管扩散，**必须用抗生素**，见 [[抗生素的谨慎使用]]；
* **气性坏疽警报**：伤口周围发黑、恶臭、按下去皮肤下"咯吱"响（有气）、人很快垮 → 极危重。没有手术条件基本救不回，只能靠早期彻底清创预防。

## 怎么做

1. **重新清创**：打开伤口，把脏东西、坏死组织清掉，见 [[清创与缝合]]；
2. **冲洗**：大量凉白开或淡盐水冲，冲得越透越好；
3. **引流**：有脓腔的，**切开让脓流出来**——脓憋在里面是感染失控的主因。切口选在最低处（让脓自己流），顺皮纹方向切；深部的别硬往里掏；
4. **热敷还是冷敷**：已经化脓、要排脓 → 温热敷促排；早期只是肿痛 → 冷敷减肿；
5. **抬高患处**：肿的胳膊腿抬高，肿退得快些；
6. **抗生素**：确认是细菌感染就用，按疗程吃够，别见好就停。

## 破伤风：最该防的是这个

沾了泥土、生锈金属的深刺伤最危险。征兆是**牙关发紧、脖子发硬、吞咽困难、身体往后弓**。一旦发作，没医院基本没救——所以**彻底冲洗 + 清创**才是一切。

## 注意

* 每天必看，固定时间看，画出红晕边界比对；
* 别用脏布、别用手直接碰伤口；
* 有异物、有坏死组织的伤口，不彻底清创，用多少消毒液都白搭；
* 感染加重的速度比你想得快——今天就处理，别等明天。
