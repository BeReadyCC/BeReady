# 止血

> 大出血几分钟就能要命，止血是急救第一技术。

## 立即知道

**直接压 → 加压包扎 → 止血带**，三级递进；压住别松、别频繁掀开看。

## 怎么做

* 直接压迫：用干净布、衣物、纱布直接用力压住伤口，持续压至少几分钟；别为了「看止没止住」而松手；
* 加压包扎：压住后再用布条或绷带绕伤口加压绑紧，绑到「止血但不阻断远端血运」的程度。

### 止血带（四肢大出血、压不住、危及生命时才用）

* 材料：宽约 5cm 的扁平布条——宽布带、三角巾卷带、宽皮带。**别用**细绳、铁丝、电线、鞋带，会勒断神经血管。
* 位置：伤口上方（近心端）5～8cm、避开关节；上臂绑上 1/3，大腿绑大腿根。
* 松紧：绑到出血停止、**远端脉搏摸不到**（手腕、脚背摸不到搏动）为止——太松止不住，太紧伤神经，标准就是「远端脉搏消失」。
* 标记：绑上就在旁边（或伤者额头）写清绑上的时间。
* 松解：绑上后尽量不松——松了可能再大出血、已成的血块脱落。要长时间转运时，先压住伤口上方的动脉，松几秒看还出不出血，还出就立刻再绑紧。

## 判断是否止住

伤口不再往外涌血、敷料不再快速湿透。

## 注意

* 止血带是「保命不保肢」的最后手段，只在压不住、要命时用；
* 别拔嵌在伤口里的异物（刀片、木刺、玻璃）——拔了可能大出血；固定住异物、绕开它压迫；
* 压住伤口后别喂水、别乱动。
