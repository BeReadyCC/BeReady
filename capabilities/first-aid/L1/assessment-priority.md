# 伤情评估与优先级

> 先判断谁最要命、先处理什么——处理顺序错了，可能白忙一场还搭上命。

## 立即知道

按「要命程度」排序：**气道 → 大出血 → 休克 → 其他**。先处理会立刻死人的，再处理能等的。

## 怎么做

* 先看呼吸：有没有呼吸、呼吸顺不顺；没呼吸或喘不上气最优先；
* 再看大出血：哪里在往外冒血；喷、涌的动脉血最优先；
* 再看意识：喊不醒、反应迟钝，说明休克或脑供血不足；
* 快速从头到脚摸一遍：找伤口、找变形、找异常。

## 判断优先级

* 第一优先（等不了）：气道堵、大出血、呼吸停；
* 第二优先（尽快）：休克、大面积烧伤、脊柱伤；
* 第三优先（可缓）：骨折、小伤口、擦伤。

## 注意

* 一次只处理一个最要命的，处理完再评估下一个；
* 伤员多时先救「能救活的」——别把时间耗在已经没有呼吸很久的人身上；资源有限，救不回的别拖累救得回的；
* 评估要快，别在一个人身上耗太久。
