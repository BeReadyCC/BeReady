# 伤口处理与包扎

> 伤口不处理，感染会杀人。清创、消毒、覆盖、包扎四步。

## 立即知道

**清水冲净 → 消毒 → 干净覆盖 → 包扎固定**。目标是防感染、促愈合。

## 怎么做

* 清创：用干净的水（烧开晾凉的水）冲洗伤口，冲掉泥沙、碎屑；挑出可见的碎屑异物；
* 消毒：有碘伏涂碘伏，没有就用烧开晾凉的水反复冲；酒精只涂完整皮肤周围，别往开放的伤口里倒；
* 覆盖：干净的纱布或布条盖住伤口，别用脏布、带毛絮的布；
* 包扎：用布条或绷带固定敷料，松紧以「不松脱、不勒断血运」为准。

## 注意

* 污染的伤口（沾土、生锈金属、动物咬）感染风险高，要更彻底清创，见 [[伤口感染与恶化]]；
* 每天查看伤口：红、肿、热、流脓 = 感染，及时处理；
* 换药时手尽量干净，接触伤口的布要干净。
