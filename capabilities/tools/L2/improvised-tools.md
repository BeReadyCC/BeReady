# 简易工具制作

> 没有现成工具，就用木头和手边废料做。木楔、木锤、杠杆、木针，几刀就能成形，干完专门的活。

## 木楔

* 选硬木，削成一头薄一头厚的尖块。
* 用法：塞进树缝、石缝、劈口，锤木楔把缝撑大——劈大柴、撬石、拆木都靠它。
* 楔比直接劈稳，不反弹、不飞片。

## 木锤

* 粗枝一段，一端留节疤或缠布加厚当锤头；或找天然分叉的硬木当 T 形锤。
* 用法：敲木楔、敲桩、装柄，不崩刃也不伤手。

## 杠杆（撬棍）

* 一根直硬木就是杠杆；垫石头当支点，力臂越长越省力。
* 用法：撬石、翻木、抬重物，见 [[挖掘与撬动]]。

## 木针

* 细硬木削尖，穿眼、缝皮、挑刺、穿绳都能用。
* 用法：缝补容器、把绳穿进窄孔。

## 注意

* 木工具怕潮怕裂，湿了晾干再用；脆了断在活里更麻烦。
* 木楔木锤用几次就松，随时换新的，别等劈到一半断。
* 砍削木料的刀见 [[刀]]；做好的结构怎么连见 [[木材连接]]、[[基本结构]]。
