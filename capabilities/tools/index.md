# 工具

> 崩溃后没有商店补货、没有修理铺兜底。一把钝刀、一根绳、一根硬木，就是你能把砍柴、搭棚、取水、分食、挖坑这些活干成干不成的分水岭。

工具是体力的放大器：同样的活，有工具省力一半，没工具累垮自己也干不快。本能力只写「怎么用工具把活干成」，绳索的打法、结构的搭法归别的章节，这里只引用，不重造。

## Level 划分

| Level | 能力目标 | 核心知识 |
|---|---|---|
| L1 · 立即可用 | 当天就能用、手头现成工具（刀/斧/锯/绳/铲/撬），不需要额外材料 | 5 |
| L2 · 现场制作 | 需要一定材料或制作步骤：磨刀、自制绳、简易木工具 | 3 |
| L3 · 长期与批量（未展开） | 金属工具获取、工具维护、批量工具制作 | 0 |

判据：L1 当天就能用、不需要额外材料；L2 需要一定材料与制作；L3 需要长期管理与批量产出。

---

## L1 · 立即可用

### 能力目标

用身上和手边现成的工具，把砍柴、搭棚、取水、分食、挖坑、撬动这些生存动作真正干得动、干得快。

### 核心知识

* [[工具的基本逻辑]]
* [[刀]]
* [[斧与锯]]
* [[绳索]]
* [[挖掘与撬动]]

### 不够怎么办

* 工具钝了、卷刃了，干不动也危险 → 进入 L2（[[磨刀]]）。
* 绳用完了、断了 → 进入 L2（[[自制绳索]]）。
* 没有现成工具，只有木料和废料 → 进入 L2（[[简易工具制作]]）。

---

## L2 · 现场制作

### 能力目标

靠磨石、树皮、藤蔓、布条和硬木，把钝工具救回来、把绳造出来、把专用木工具做出来——让工具不断供。

### 核心知识

* [[磨刀]]
* [[自制绳索]]
* [[简易工具制作]]

### 不够怎么办

* 金属件严重损耗、需要更稳定耐用的工具 → L3 的 [[金属工具]]（方向）。
* 工具长期频繁使用需要保养、防锈、更换易损件 → L3 的 [[工具维护]]（方向）。
* 同行家人多、需要多套工具并行 → L3 的 [[批量工具制作]]（方向）。
