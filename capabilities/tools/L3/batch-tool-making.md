# 批量工具制作

> 一把工具撑不了多久：天天砍柴挖土，木柄几个月就松，刃几个月就钝。一家人几双手、几样活，就得备几套。批量做是为了「坏了随手换上」，不是多囤。

## 立即知道

批量的关键**不是做得多，是做成一个规格**——同样的柄长、同样的孔径、同样粗细的绳。

规格统一了，坏一把能拆零件救另一把；规格乱了，一堆没用的半成品。

## 一、先定规格（半天的事）

1. 挑一把最好用的当**样**，量下来：柄长、柄粗、插头长度、刃角、绳粗；
2. 把这些尺寸**刻在一根木尺上**，以后所有同类都照这根尺做；
3. 至少记这几件：砍刀柄、斧柄、铲柄、木楔、绳粗；
4. **定了就不改**。改一次就等于全部互换件作废。

## 二、一次备料（砍一批、晾一批）

* **木柄料**：选直、无节、不扭的硬木（栎/柞、槐、榆、白蜡、山核桃）。**顺纹劈成方料**比圆枝抗弯。
* **晾**：阴凉通风处阴干，几周到几个月，干到掂着轻、指甲掐不出印。**湿木做柄一定松脱**。
* **多备三分之一**：下料、削形、装柄都会出废品。
* 木料来源与挑选见 [[木材]]，一次别把同一片林子砍光。
* **绳料**：一次剥够一批（树皮 / 藤 / 麻），成束搓，一次搓够一整轮用量，见 [[自制绳索]]。

## 三、流水线（人多才快）

* 分工：一人锯段 → 一人削粗坯 → 一人钻孔装楔 → 一人磨刃开锋。**每道工序做 10 件再交接**，比一人包干快得多，规格也更齐。
* 一个人做就「同一道工序做完一批」：先把所有柄削完，再统一装，再统一磨——少换工具、少来回。

## 四、木柄与装配（照做）

1. 照木尺锯段，两端各留 2–3cm 余量；
2. 削成圆棒或椭圆棒，一端削细做插头，**削到插进孔里要用力敲才进为准**；
3. 装头：从头顶往下敲，顶到底敲实；
4. 上端锯一道缝，打进木楔，把木头挤开咬死（楔见下节）；
5. 干透后会缩，松了再补一个楔，见 [[工具修理]]；
6. **另留 3–5 根光柄备用**——柄先坏，头还在。

## 五、刃具批量（有废钢时）

* 废钢挑料、退火、成型、淬火、回火按 [[金属工具]] 走；
* 批量好处：一次退火、一次起炉，**同规格的一起淬火**，火色好互相对比；一件一件做白白多烧几炉火；
* 磨刃：先全批走一遍粗石开斜面，再全批走一遍细石出锋，见 [[磨刀]]。

## 六、石刃批量（没有金属时的主力）

* 选料见 [[黏土与石料]]（燧石、石英、河卵石，敲之声脆）。
* **打剥制片**：手持石核、用卵石当锤，斜着磕石核边缘，崩下薄石片——一次能崩几十片；台面垫在膝上或软土上，别悬空硬砸。
* **修刃（压剥）**：用硬木棒或鹿角尖抵住石片边缘，一点一点压出细齿——比砸出来的口平整、耐用，边缘不崩不飞。
* **一批做三种**：凹刃刮削器（刮皮、刮肉、修木）、直刃切割刀（割绳、开皮）、尖刃钻（钻木、穿孔）。崩断的片子留作小刃，不扔。
* 石刃易崩，**多做、多备、崩了就换**。

## 七、绳、楔、木钉的批量

* **木楔**：一次削 20–30 个，同一木尺规格，装一袋备用；劈柴、撬石、固柄随手抓，做法见 [[简易工具制作]]。
* **绳段**：按用途分两种规格——绑扎段（1–2 步长）、拴重段（2–3 步长），粗细判断见 [[绳索]]。
* **木钉 / 木桩**：削一批同规格的，搭棚、固土、楔缝都能用。

## 八、每批必查（批量最容易混次品）

| 查什么 | 怎么查 | 不合格怎么办 |
|---|---|---|
| 柄 | 提起来晃，看头动不动；看柄头有没有新裂缝 | 松了补楔；裂了换柄 |
| 刃 | 在木头上砍两下 | 崩口、卷刃的挑出来重磨；救不回的降级当撬具 |
| 绳 | 双手拉一拉 | 起毛、脆断的降级当绑绳，不上承重 |
| 楔 | 敲两下看会不会劈开 | 有暗裂的当柴 |

**抽查十分之一**：不合格就整批回炉重做那一道，不要一件件赌。

## 九、做多少（一家四口参考量）

| 工具 | 数量 | 说明 |
|---|---|---|
| 砍刀 / 大刃 | 2–3 | 主用一把 + 备用 |
| 斧 | 1–2 | 劈柴主力 |
| 锯 | 1 | 齿难修，别硬别弯 |
| 小刀 | 每人 1 | 天天用，最容易丢 |
| 铲 / 镐 / 撬 | 各 1 | 挖坑、翻地、撬石 |
| 木楔 | 20–30 | 消耗品 |
| 绳 | 30–50m | 分 3–4 段，不同粗细 |
| 备用柄 / 柄料 | 3–5 根 | 柄先坏 |

## 注意

* 打石、淬火、敲打都有声音和火光，需要低调时**分散时段、分散地点**做，别在一个点集中搞出动静，见 [[工具的基本逻辑]]。
* 成品**别全堆一处**：一次火、一次水就全没了；常用的随身，备用的分开存放，见 [[工具维护]]。
* 批量不是越多越好：做多了占地方、受潮变坏、还要人守。按「坏一件补一件」保持库存。
* 木器怕暴晒怕火烤，成品与半成品都存阴凉干燥处。
