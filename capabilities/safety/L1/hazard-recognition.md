# 危险识别

> 危险识别是一切安全能力的第一步——没看到的危险无法躲避，看到的风险才谈得上选择。

## 立即知道

进入任何新环境，先做一遍"五感扫描"，按四类危险归档：

| 类型 | 典型信号 | 例 |
|---|---|---|
| 会塌 / 会砸 | 裂缝、倾斜、悬空物、异响 | 坠落广告牌、危墙、悬冰 |
| 会淹 / 会冲 | 水线痕迹、上游雨云、低洼积水 | 山洪沟、涨水桥涵 |
| 会燃 / 会爆 | 燃气味、油渍、泄漏设备、火花源 | 燃气泄漏、油桶、裸露电线 |
| 会毒 / 会病 | 异味、死鱼死虫、雾状气体、病媒 | 一氧化碳、化学品、疫水 |

**改变环境的事件之后必须重扫**：地震、暴雨、大风、爆炸之后，之前的"安全"结论全部作废。

## 怎么做

### 三步扫描法

1. **先抬头**：头顶有什么会掉下来（坠物、断枝、结构）；
2. **再看脚下**：地面是否可靠（空洞、湿滑、不稳定堆积物）；
3. **最后看四周**：撤离路径上有无障碍，危险源在哪个方向。

### 记住"新的 = 可疑的"

* 环境里**新出现**的东西最值得怀疑：新的气味、新的水痕、新的裂缝、新的动物行为；
* 人群突然集中或奔逃，本身就是最高等级的危险信号——别逆着人流去凑近看。

### 说不清就按危险处理

* 识别不出来源但确实异常（气味、声音、感觉）时，**先按存在危险行动**（离开、隔离），再慢慢弄清楚——误报的代价远小于漏报。

## 注意

* 熟悉环境最危险——"一直这样"不是安全证据，注意是"一直没事"还是"没出过事"；
* 夜间与疲劳时识别能力骤降，重要判断放到白天、休息后做；
* 移动中不刷手机，它吞掉全部注意力；
* 系统化的观察方法与信号解读是 L2 的 [[环境观察]]、[[危险信号]] 主题，L1 只保证"扫过一遍"。
* 绝大多数事故发生前都有可察觉的信号，区别只是有没有人看。五感扫描 + 事件后重扫 + "新的=可疑的"，把"识别危险"从天赋变成流程。
