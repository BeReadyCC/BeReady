# 电气危险

> 电看不见、闻不到、跑得比任何反应都快——电气安全的全部内容是：**不确认断电，就不接触**。

## 立即知道

| 场景 | 底线规则 |
|---|---|
| 垂落电线 | 一律视为带电；10 m 外绕行，不跨步接近 |
| 车辆压到电线 | 留在车内；必须离开时双脚并拢小步跳出 |
| 积水区域 | 水浸过的插座、电器、线路按带电处理 |
| 有人触电 | **先断电再施救**，直接拉人是第二触电者 |
| 潮湿手 / 环境 | 不碰任何开关与插头 |
| 发电机 | 室外使用，严禁接入室内电路（反送电会让线路带电电死人） |
| 雷雨天气 | 远离高处、孤树、开阔地、水面；低姿蹲下、双脚并拢 |

## 怎么做

### 雷雨天气（野外）

* 打雷前就离开：山顶、山脊、孤立大树、开阔平地、水面、金属围栏——这些是雷击高发处；
* 来不及撤时：找低洼处蹲下，双脚并拢、脚跟落地，减少与地面的接触面积；别平躺、别靠墙；
* 金属长物（杖、伞、锄头）先放下，别举过头顶；
* 雷声过后约 30 分钟再回开阔处。

### 日常防护

* 知道家里 / 驻点的**总闸与分闸位置**，断电从总闸开始；
* 湿手不碰电、金属不插电、破损线不将就——发热、异味、火花是线路的求救信号，见即断电排查；
* 大功率电器不同插座并联，防止过载起火。

### 水浸与灾后

* 水进屋先断总闸再回去活动，宁可白断不能漏断；
* 被水泡过的电器与线路，**干透并确认前不再通电**；
* 灾后看到电线垂落或有电火花，按 [[安全距离]] 的 10 m 规则处理，并提醒身边的人远离。

### 有人触电

1. 断电：拉总闸，或用干燥木棒、塑料椅挑开电线——**绝不徒手拉**；
2. 脱离电源后判断呼吸，无呼吸立即心肺复苏，按 [[急救]] 能力流程执行；
3. 触电者的"看似无碍"不可信：电击对心脏的延迟伤害可能几小时后才出现，脱离后静养观察。

## 注意

* 自行车、风筝、竹竿接触架空线的死亡事故反复发生，任何长杆不举过头顶移动；
* 断电后仍要验证：用验电笔或确认电器彻底无反应——**"应该没电"不是断电**；
* 发电、蓄电池等临时电源同样致命，接线与保险不得随意改动；
* 用电起火的处置（先断电再灭）见 [[火灾安全]]。
* 电流对人体的伤害在毫秒级完成，事后的勇敢无济于事——电气安全只能前置：知道总闸在哪、默认一切带电、断电后仍要验证。
