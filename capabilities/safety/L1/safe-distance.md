# 安全距离

> 对危险源，距离本身就是防护——不够了解的危险，一律放大距离。

## 立即知道

常见危险源的 L1 距离底线（宁大勿小）：

| 危险源 | 距离底线 | 原因 |
|---|---|---|
| 坠落物范围 | 至少物高 1.5 倍外绕行 | 坠物会弹跳偏移 |
| 燃气泄漏区 | 远离至上风向，越远越好 | 蒸气扩散范围不可目测 |
| 水域（流动） | 不下水，岸边留 2 m 以上 | 湿滑与暗流 |
| 水域（激流） | 远离整个河滩 | 脚踝深的水能冲倒成人 |
| 火场 | 与着火建筑保持一个街区 | 坍塌、爆炸、飞火 |
| 倒电线杆 / 垂落电线 | 10 m 以外，禁跨步接近 | 跨步电压 |
| 不明烟雾 / 气体 | 上风向、高地 | 气体比空气重会积在低处 |
| 人群拥挤处 | 沿边缘斜向离开，不逆流 | 踩踏挤压 |

## 怎么做

### 使用规则

* **识别出危险的第一反应是拉开距离**，不是靠近确认——好奇是最常见的凑近原因；
* 对"说不清的危险"默认套用同类中最大的距离；
* 带人同行时，距离底线以最弱者（儿童、伤者）为准，不以自己为准。

### 观察位置

* 保持距离的同时**留好退路**：站在危险源侧后方，不站在它与出口之间；
* 看热闹的位置 = 最差位置，宁可不看。

## 注意

* 距离表是底线不是安全值——风、坡度、介质都会放大危险半径（上坡的火、顺风的有毒气）；
* 儿童对距离没有概念，移动中要牵住，静止时要有人盯；
* "再近一点看清楚"不值得任何风险；
* 危险源的动态（火势、水位、人群规模）每分钟都可能变化，拉开距离后持续观察，见 [[危险识别]]。
* 几乎所有可避免的伤害都有一个共同前奏：离得太近。距离是最便宜的防护——不需要装备、不需要技术、当场生效。把"默认拉远"变成条件反射，L1 的安全就完成了大半。
