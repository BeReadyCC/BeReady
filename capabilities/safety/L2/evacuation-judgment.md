# 撤离判断

> 撤离的难点不是怎么走，而是"什么时候走"——多数人死在犹豫，不是死在路上。

## 立即知道

撤离的**黄金窗口在危险"明显"之前**：等水到脚边、火到门口再走，往往已经晚了。

两类判断：环境已危险（必须走）、环境将危险（提前走）。**宁可提前撤、白走一趟，不可晚撤一步。**

## 先定触发线（趁没事的时候写下来）

| 危险 | 触发线 |
|---|---|
| 洪水 | 水位涨到岸边刻痕以上一掌；听到上游低沉的轰鸣 |
| 火灾 | 下风向闻到明显烟味；看到火星飘落；灰烬开始落下 |
| 地震 | 主震后屋子出现新裂缝、门框卡死、墙面持续掉灰 |
| 山体 | 出现新裂缝、树木倾斜、坡脚渗浑水、小石持续滚落 |
| 气体 | 眼睛喉咙刺痛、闻到化学味、鸟或虫成片死亡 |

写在纸上、贴在墙上——**出事的时候你没有判断力**。

## 什么时候走

两类信号，哪个先到按哪个：

* **环境**：到触发线了 → 走；
* **自身**：补给见底、有人受伤、体力耗尽、天要黑 → 也走。

## 走的准备

* 备两条路线，都提前走过、标过，见 [[安全路线]]；
* **轻装**：只带水、食物、药、御寒、照明、工具——重了走不远，走不动的撤离等于没撤；
* 出发前用 2 分钟做完：关火、断燃气、关电、带走能带走的水、把门关上（挡火挡烟）；
* 记住出发时间——后面算时间全靠它。

## 注意

* 撤离是**单向**的：出发就别计划"回去取东西"。值钱的带走，带不走的放弃；
* **白天撤优于夜晚撤，提前撤优于雨雪中撤**——天气会让路线失效；
* 犹豫的代价是窗口关闭：确认危险就动，不能确认就按危险准备；
* 唯一"不撤"的情况：撤离路线本身比留下更危险（比如唯一出路要过河，而河正在涨）。这时改成就地避险——往高处、往结构稳的地方挪，见 [[撤离]]。
