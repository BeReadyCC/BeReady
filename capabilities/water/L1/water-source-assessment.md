# 水源基本判断

> 判断水源，外观只是线索，不是安全证明。

很多危险水源看起来完全正常。所以不能只靠：

* 清澈；
* 无异味；
* 无明显颜色；
* 没有漂浮物。

这些只能帮你发现明显问题，不能证明能直接喝。

## 立即知道

面对陌生水源，先问四个问题：

### 1. 水从哪来？

自来水系统、雨水、河流、湖泊、井、水库、积水。

### 2. 上游有什么？

污水、排泄物、垃圾、工业设施、农业活动、燃油、化学品。

### 3. 最近发生了什么？

洪水、地震、管道破裂、火灾、化学品泄漏、污水系统故障——灾害会改变原本安全的水源。

### 4. 现在还有没有官方消息？

如果仍有机构在通报某水源不能用，能收到就照办；但**别把命押在"等通知"上**，自己判断为主。

## 一个简单原则

把水源风险粗分四档：

**已知安全** → 优先用。

**来源可靠、但当前不确定** → 进一步处理。

**自然水源、有微生物风险** → 处理后用。

**怀疑化学污染** → 换水源。

最后一种最关键：水里有燃油、有毒化学品或放射性物质，普通煮沸、消毒救不回来。

## 怎么做

拿不准水源安全时：

1. 不直接喝。
2. 尽量找更可靠的。
3. 只是微生物风险 → 走 [[基本饮水处理]]。
4. 怀疑化学污染 → 别指望家庭净水解决。

## 注意

**过滤 ≠ 消毒。**

过滤能减少浑浊物和部分污染物，但不能简单认为普通过滤后就安全可喝。
