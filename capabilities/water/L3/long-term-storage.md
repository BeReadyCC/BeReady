# 长期储水与轮换

> 断水不是几小时的事。趁还有水，先攒下一批能撑过荒季的，并且让它一直是好的。

**分工**：[[安全储水]]（L1）管**手上这批水**放哪、多久内喝完，按天算；这一节管**长期储备**——备多少、怎么轮换、怎么藏，按月算。

## 立即知道

长期储水就是三件事：**备够量、定期换、别让人看见**。

底线参考：

* 每人每天 **3～4 升**（喝 + 最基本的入口用水），高温、重体力更多；
* 能存多少存多少——存得越多，断水后撑得越久；
* 先保证"够喝"，再谈"够用"；
* **储水只是争取时间**，长期仍要靠 [[稳定水源]]。

## 备多少：先算，再攒

按"要撑多久"倒推，不是看有几个桶。

| 想撑 | 每人需要的量（按 3.5 升/天） |
|---|---|
| 1 周 | 约 25 升 |
| 1 个月 | 约 105 升 |
| 3 个月 | 约 320 升 |
| 1 年 | 约 1300 升 |

* 拿人数乘一遍，就是目标量：**4 口人撑 3 个月 ≈ 1260 升**——别指望一次凑齐；
* **分次攒**：每次外出带回来的水，留一部分进储备不动，剩下的才用于日常；
* **分多处存**：单个容器损坏或被发现，不会全损。

## 怎么装

```text
洗容器 → 水先处理过 → 装到接近满 → 标日期 → 避光阴凉存
```

* **容器上至少标两样**：饮用 / 非饮用、灌装日期；
* **装水前**：容器和盖子洗净、冲净、晾干；水最好先煮沸晾凉或消毒再装；
* **装水时**：装到接近满，只留一点点膨胀空间——**空气越少，水坏得越慢**；
* **装水后**：避光、阴凉；别放灶台边、窗台上、车里。

拿什么容器见 [[储水容器]]。

## 多久换：查什么、怎么换

**每月看一次**，四条：

* 水位有没有无故下降（漏了，或被碰过）；
* 水有没有变浑、出现絮状物或悬浮物；
* 闻有没有异味（霉、腐、油、化学）；
* 容器有没有裂缝、变形、内壁发黏。

出现任何一条 → **不喝，倒掉、洗容器、重新装**，不要"稀释着喝"。

* 自己装的水大约**每 6 个月**换一次（按月检查做，到期就换）；商业瓶装水按生产商标注的日期管理；
* **先存的先用**：新的放里面、旧的放外面，取用时自然先取旧的；
* **开过封的桶更要勤查**——每取一次水，桶里就换进一批空气；
* 换下来的旧水不浪费：降级去做洗涤、冲刷、浇地。

## 怎么藏

**储水位置和规模本身就是暴露。**

* 不摆在门口、窗边、通道这些一眼能看见的地方；
* 分散、遮盖（布套、堆物后面）、别贴统一标签在外侧；
* 取水放在固定时段，动作小、少声响；
* 外人能进出的场合，别让"有多少水"成为看得见的信息。

## 注意

* **别只看"水还很清"就认为安全**——很多致病菌让水看起来毫无变化；
* 水质还受容器、储存环境、温度、光照、开启和取用方式影响；取用环节的污染见 [[防止二次污染]]；
* 长期缺水时，**水通常比食物更早成为约束**，规划和食物储备一起做，见 [[长期食物计划]]。
